该用哪种挑法挑训练数据？

训练预算固定时，OmniSelect 先让好几种数据选择策略各自挑出一份子集，再用同一个下游模型，在单独留出的验证数据上比较这些子集，决定交出哪一份。你最后拿到的是一组记录下标，外加这次选择每一步的证据。

先读这里 · 论文讲了什么

OmniSelect 到底做了什么，新在哪里

一句话从一个混着坏数据的数据池里挑固定数量的训练记录，没有任何一种挑法在所有任务上都安全。OmniSelect 先用三种质量信号按分工组合出一批完整的候选挑法，再用这个任务自己的下游模型，在留出的验证数据上比较这些挑法，选出最好的那份子集交付。

依据当前 PVLDB 中文稿（投稿稿件）。本节讲论文本身，后面各节讲代码怎样实现、和论文哪里不一样。

1　要解决什么问题

预算有限时挑训练数据，是对基础模型有实测收益的数据准备步骤。不同任务的学习器用数据的方式也不同，有冻结 CLIP 特征加线性头、以上下文方式预测的 TabPFN-v2、在滑动窗口上训练的预测器，以及在文本上微调的 SmolLM2。一条候选记录可以用三种信号描述。

  • 真实性，记录是否完好，即内容和标签能否通过逐条的损坏检测器（例如和嵌入空间近邻的标签冲突、平直或打乱的传感器窗口、低质量文本）。
  • 影响力，学习器对这条记录的反馈，即在干净参照数据上拟合的模型给它的标签多大的似然。
  • 覆盖性，选出的集合对数据池分布覆盖得怎样。
例 1，最好的挑法随任务反转CIFAR-100 上从 4000 张图里挑 2000 张，Auth-only（只看真实性）准确率 0.432，随机 0.398，Coverage 0.345。换到从头训练 ResNet-18 的原生 CIFAR-10，Auth-only 0.841，随机 0.881，Coverage 0.889，顺序完全反过来。Electricity 上用 TabPFN-v2，Auth-only 的 AUC 0.840，随机 0.859，Coverage 0.867。除随机外展示的 11 种策略，每一种都至少在一个任务上低于随机，利用验证反馈融合三种信号的 DMF-pub 在六个任务上低于随机。
例 2，各信号失效的地方互补CIFAR-100 上 Auth-only 只选进 1.3% 的标签翻转图像，但准确率 0.432 明显低于 OmniSelect 的 0.487，因为最“真实”的 2000 条也是最典型、最容易的。Electricity 上 Coverage 选进了 99.3% 的特征损坏行，因为损坏记录离其他记录远，分散挑选最先挑到它们。把信号加权求和会同时继承这两种失效，即使事后用测试分数挑融合权重，最好的融合在 CIFAR-10（CLIP）、Electricity、Text 上仍不如某个不融合的策略。

2　难点在哪

  • 好策略从数据池里读不出来。两个数据池可观测量完全一样的环境，可能要求相反的选择。同一个统计量（例如到其他记录的距离），在 Electricity 上标出的是损坏行，在 CIFAR-10 上标出的是有用的稀有图像。
  • 组合信号让候选成倍增加，每个候选都要消耗验证数据。在更多策略中选举需要更多验证单元，而且在给策略排序的同一份数据上调它，会让它在这份数据上分数虚高。
  • 每次验证都要训练一次下游模型。给 m 条策略排序至少要 m 次预算规模的训练。

3　创新点

创新 1

信号按角色协同

协同策略分四步。准入，保留准入分数（真实性或学习洁净度）最高的 ⌈ρk⌉ 条。离群过滤，剔除到数据池第 ν 近邻距离的稳健 z 分数过大的记录。近重复过滤，距离很近的记录连边，每个连通分量只留分数最高的一条。代表性选择，用 herding（匹配平均嵌入）或 k-center（最远点优先）在剩下的记录里挑 k 条，不够再按准入分数回填。

每种信号只承担它可靠的角色。真实性负责查标签冲突。原来让 Coverage 选进坏行的几何结构，在过滤器里改为剔除这些行。代表性选择恢复分散程度，但只在通过前几步的记录上运行，k-center 不再把预算花在尾部。

创新 2

学习洁净度

构造划分的记录是干净的，数据池是干净和损坏的混合。在逐记录特征上训练一个分类器区分“来自构造划分”和“来自数据池”，它的输出就按和干净数据的相似程度给池中记录排序。分类任务的特征对应三种信号，近邻标签一致率、交叉拟合模型给的标签概率和间隔、到近邻距离的对数，所有分数都交叉拟合得到。

固定的检测器编码的是固定规则，而哪种信号组合对应干净记录随任务而变。学习洁净度在每个任务自己的数据上拟合出来，排干净记录的 AUC 在 CIFAR-100、TEP21、Electricity、Text 上都高于真实性信号（0.941 对 0.896，0.851 对 0.742，0.850 对 0.652，0.886 对 0.704）。

创新 3

三份验证数据各管一件事

验证数据分成构造（V_con）、排序（V_rank）、确认（V_conf）三份。V_con 用来构造和筛选候选（逐次减半、共识投票、权重坐标搜索），然后冻结候选列表。V_rank 给冻结的候选打分，参照是可作参照的策略（总含随机）里最好的，挑战者是全部候选里最好的，挑战者超过参照一个预设边距才采纳。V_conf 对当选的一对策略做配对核验，给出任意时刻有效的证书，但不改变选举结果。

在一份数据上构造候选，在另一份上选举，选举就不会被构造时的调参污染，定理 3 的误差界才成立。参照总含随机选择，所以当选结果有一个不低于参照太多的保证。

创新 4

训练一次缓存

每个不同的子集只拟合一次下游模型，这次拟合在所有划分上打分，筛选、排序、核验和最终报告读的都是同一个模型。

几个候选输出同一个子集时不再重复训练，一次裁决的计算量只有几十次全数据训练。

4　方法按步骤走一遍

  1. 统一记录把图像、时间序列窗口、过程测量、表格行、文本文档都标准化成统一记录，每条带模态、内容和嵌入。
  2. 算信号真实性取各检测器排名的逐记录最小值。影响力是在 V_con 上拟合的参照模型给观测标签的对数似然，并在同一标签内排名，避免预算集中到参照模型最有把握的类别。覆盖性用嵌入密度和压缩统计量。
  3. 构建候选（第一层）单信号策略、固定融合网格（权重 × 真实性阈值 θ × 多样性强度 ω，ω>0 时按最大边际相关性贪心挑）、协同网格（准入分数 × 准入宽度 ρ × 内部选择器）、学习洁净度 top-k，以及策略库里的 DSDM、GLISTER、GradMatch 等方法。
  4. 筛选并冻结在 V_con 上逐次减半筛选融合和协同候选，加上共识投票和坐标上升两个合成候选，冻结组合。
  5. 选举（第二层）在 V_rank 上打分，挑战者比参照高出 η·|参照效用| 才采纳挑战者，否则保留参照。
  6. 核验与交付在 V_conf 上计算配对增益、自助区间和投注财富，财富越过 Kδ 就给出证书。返回当选子集。

5　理论结果，一句话版

结论它保证了什么成立的前提
定理 1（只读分数的识别界限）存在两个可观测量完全相同的环境，一个里某组记录有害，另一个里同一组是学习器需要的边界记录。任何只读分数、不读下游模型反馈的规则，在其中一个环境里的期望超额风险至少是差距的一半，随机选择恰好达到这个下界。所以挑策略必须读下游模型的留出效用。只读数据池可观测量的规则，包括按数据特征挑策略的选择器。
定理 2（验证复杂度下界）在 m 条策略里选出领先 γ 的那条，最坏情况下需要 q ln mγ² 量级的共享验证单元，q 是各策略逐单元分数差的配对二阶矩（候选越常给出相同答案，q 越小）。裁决达到这个量级。m≥16，0<γ≤½，γ/2≤q≤½。
定理 3（裁决的误差界）当选策略相对每条可作参照策略的差距不超过一个置信半径，两条策略在验证单元上分歧越少，半径越小。采纳挑战者时，真实增益大于切换门槛减去半径。指标是 [0,1] 内逐单元分数的均值或 AUC 这类 U 统计量，验证单元独立抽样，候选只读构造划分，排序模型就是报告模型。
命题（协同的纯净度与覆盖）从准入集合里选出的子集，期望污染比例至多 1 − min{1, π(t−e)1−t+e}。k-center 选出的集合到目标集的最大距离不超过 h(T,A)+2r_k(A)。准入越窄，纯净度的界越好，但覆盖可能变差，所以要在网格里放多个宽度。洁净度分数误差有界，最终可用的点都在准入阈值内。
命题（确认证书）确认阶段越过 Kδ 就认证，在任意读取长度上，把有害采纳被认证的概率控制在 δ 以内。确认单元独立于构造和排序。

7　读完自测

为什么不能离线算好一个“最好的信号组合”直接用？

定理 1 说明，只读数据池信息的规则一定会在某个环境里出错。实验也显示每种固定策略都在某个任务上低于随机。必须让该任务自己的下游模型在留出数据上做裁决。

协同策略和加权融合的区别是什么？

融合把几个信号压成一个分数再排序，会同时继承各信号的失效。协同让每个信号在不同步骤承担不同角色，真实性负责准入，几何结构负责剔除离群和重复，代表性选择器负责分散。

为什么验证数据要分三份？

在同一份数据上既构造候选又选举，会让构造时调过的候选分数虚高。三份分开后，选举只读排序划分，核验只读确认划分，理论误差界才成立。

学习洁净度的分类器是在干净标签上训练的吗？

不是。它区分的是“来自构造划分”和“来自数据池”，池里也有很多干净记录。理想条件下它和“是干净的概率”排序一致。

OmniSelect 会修改记录吗？

不会。它只挑选记录，输出一组下标。实验里的损坏是事先注入的实验设置。

数据到底变了什么

按记录数算预算时，所有策略一般都从同一份 N 条记录里挑出 k 个不同的下标。原来的 N 条记录仍然留着，方便追踪。中间算出来的信号矩阵和邻接图只是辅助量，不会替换原始样本。

数据的变化分三类。第一类是做实验时注入噪声，或者读入人工噪声标签。第二类是算分数、特征和候选下标。第三类是选中的子集用于模型拟合或上下文条件化。只有第一类会改变实验数据池里的内容，这一步是实验设置，不是 OmniSelect 的清洗步骤。

真实性分数高，不代表标签已知是干净的

CLIP 赛道的主真实性通道实际调用的是 knn_agreement_and_novelty，算的是近邻标签和观测标签的一致率。另一条 auth2_only 候选可以用更复杂的折外概率加检测器排名组合。这两条路径不能混为一谈。

洁净度分数并不是拿“是否干净”的标注直接训练出来的

训练目标为 1 表示记录来自干净的构造集，为 0 表示来自混合数据池。池里标为 0 的记录其实也有很多是干净的。理想情况下，这种“来源分类”的分数和“干净的后验概率”排序相同。实际中它还受特征、分布匹配程度和拟合误差影响。

F_pool ∈ ℝN×5, F_con ∈ ℝn_con×5
w_pool = 0.5 / n_pool_fit，w_con = 0.5 / n_con_fit代码再乘上这次拟合的总记录数，两种来源各占一半的相对权重不变。主案例给 pool 打分用 5 折，每个来源分类器拟合 3200 条 pool 和全部 240 条 con，单条 con 的权重约是单条 pool 的 13.33 倍。来源 CV AUC 另外做双侧留折，这时比例约为 3200/192，即 16.67 倍。这是辅助分类器的训练权重，不是最终样本的损失权重。

冻结和门槛的控制流程，包括容易漏看的分支
  1. 先把参照策略的子集算出来。参照策略不参加融合或协同的筛选。
  2. 生成全部 fusion cells，按选中 ID 排序后的哈希去重。协同网格单独去重、单独筛选。
  3. 把融合和协同的入围者、clean_top 这类额外挑战者、参照策略都放进候选。如果没有参照策略并且按记录数算预算，控制器会用 coverage 作为后备参照。
  4. 在 V_con 上算构造分数，生成投票和坐标上升两个挑战者。构造候选时出错，会记进 construction_errors，不会假造一个有效结果。
  5. 检查每个子集的下标合法、不重复、预算正确，然后冻结，在 V_rank 上排序。分数相同时保持候选原来的顺序。
  6. best_ref 是参照策略里 u_rank 最大的那个。挑战者是非参照候选按 u_rank 从高到低的前 K 个。margin 检验对每个挑战者都做，但采用第一个通过的。所有阈值都基于同一个 best_ref，所以这和直接拿最强挑战者去比是一样的。
  7. 默认 precheck.enabled=True，但 decide=False，所以它只记录还有多少提升空间，不改变决定。看到 precheck 有输出，不代表执行了提前退出。
  8. audit 再拿同一个 best_ref 和前 K 个挑战者比较，读 V_conf，返回 Election、所有候选、筛选记录、计时和错误列表。

为什么 K/δ 能管住多重比较，以及为什么它不等于“95% 会变好”

论文的原假设是 Δⱼ≤−ε。如果确认单元和构造、排序都独立，并且每一步都满足条件期望 E[zₜ|过去]=Δ，λₜ 只由过去决定，那么每一步的乘子非负，条件期望不超过 1。因此 M 是非负上鞅。

由 Ville 不等式，每个有害候选在任何时刻越过 K/δ 的概率最多是 δ/K。最多 K 个候选取并集，整体出错概率最多是 δ。K=3、δ=.05 时，每个候选分到约 .0167 的出错上限，门槛是 60。如果每个候选各用门槛 20，就达不到同样的整体保证。

没通过认证，不等于证实了它有害。通过了，也不是“这个候选有 95% 的概率更好”这种贝叶斯后验。ε>0 的检验排除的是平均改进 ≤−ε 的情况，并不保证改进严格为正。

六个理论结果，各自回答一个问题

定理 1，只看分数为什么会遇到分不清的情况

两组记录在可观测信息上完全一样。在环境 E₁ 里，a=0 这一组有害，风险是 γ·α。在环境 E₂ 里，它们是学习器需要的边界记录，风险是 γ(1−α)。只读可观测量的规则在两个环境里的平均 α 相同，所以两个风险里较大的那个至少是 γ/2。α=1/2 正好达到这个最坏情况下界。定理说的是存在这样的难例，并没有说随机选择在每个真实任务上都最优。

定理 2，候选多、差距小时，需要多少共享验证数据
最坏环境的超额风险 ≥ (γ/2)[1−(nγ²/(2q)+ln2)/ln m]
n ≤ q ln m/(2γ²) ⇒ 某个环境的期望超额风险≥γ/4

条件是 m≥16、0<γ≤1/2、γ/2≤q≤1/2。证明用一个共同激活位和 Bernoulli 分数构造 m 个环境，用 KL 上界控制互信息，再用 Fano 不等式。n 按所有策略共享的验证单元来数，不是每条策略各自再要 m 份独立样本。q ln m/γ² 这个量级针对的是最坏的分布族，不能当成某个具体任务所需样本量的精确预测。

定理 3，配对裁决的半径具体怎么算

候选、构造数据和训练随机性都固定之后，对每一对候选，在同一个验证单元上取分数差 Dᵢ∈[−1,1]，q̂=mean(D²)。两个分类模型大多同时答对或同时答错时，D=0 的情况多，配对半径就可能更小。

L=ln(3·C(m,2)/δ₁)
Q=min(1,q̂+√(2q̂L/n)+2L/n)
B=√(2QL/n)+2L/(3n)
备选范围半径 2r₁=2√[ln(2m/δ₁)/(2n)]

两类界各自的水平是 δ₁。事后直接取较小的那个，按论文说明要合并成 2δ₁，不能还写成 δ₁。如果想要总水平 .05 又取两者中的较小值，可以各分 .025。这个计算器每类用 δ₁=.025。它只是解释公式的工具，不是实际控制器的切换门槛。

结论有三条。(a) 相对每个参照，最多差一个配对半径。(b) 相对整个候选集，还可能多付一个没有切换造成的 τ。(c) 采用挑战者时，真实增益大于经验切换门槛减去半径。所以经验增益 >0 不能自动推出真实增益 >0。

AUC 的单元是正负比较核，并非所有 n₊n₋ 个配对都相互独立，有效 n=min(n₊,n₋)。对 macro-F1、MASE、PPL，程序用代理量做有界核验，代理量的区间不能当成原始指标也享有同一条定理的保证。

命题 1，协同策略的纯净度和覆盖怎样分开刻画
污染比例的条件期望 ≤ 1−min{1, π(t−e)/(1−t+e)}
目标集到选中集的最大距离 ≤ h(T,A)+2r_k(A)

第一式的前提是拟合出的来源分数误差 ≤e，并且最终可用的点都在阈值 t 以内。第二式是欧氏最远点优先对 A 的 2 倍近似覆盖，再加上 T 到 A 的偏移 h。准入收得越窄，纯净度的界可能越好，但目标里的稀有区域会离 A 更远。所以 ρ 是要按任务挑的宽度，并非越小越好。

命题 2 与功效备注，证书有效和容易通过是两回事

任意时刻有效，靠的是上一节的非负上鞅和并集界，不要求事先定好在哪里停。功效备注另外假设 z 独立同分布、Δ>0、ε=0、λ 固定且合法，讨论的是在有限的 n 内越过门槛的概率。

ψ=λΔ−λ²q，a=ln(K/δ)，ℓ=ln(1/β)
ln M_n ≥ nψ−λ√(8nqℓ)−8λℓ/3 （概率至少1−β）

右端达到 a，才保证在这个样本量下有相应的功效。这是充分条件，常数可能偏保守。不能从“证书有效”推出 160 个确认样本一定够证明一个小幅收益。实际代码用的是自适应的 aGRAPA，备注里固定 λ 的功效公式不能不加说明地当成这个实现的精确检出率。

  39      """Log-wealth and stakes of the aGRAPA betting sequence on ordered observations y in [-(1-eps), 1+eps].
  40
  41      lambda_1 = 0. For t >= 2 the stake uses the mean mu and the variance sigma2 of y_1..y_{t-1}
  42      and equals clip(mu / (sigma2 + mu^2), 0, 1 / (2 (1 - eps))).

  45      n = len(y)
  46      cap = 1.0 / (2.0 * (1.0 - float(eps)))
  47      csum = np.concatenate([[0.0], np.cumsum(y)[:-1]])
  48      csq = np.concatenate([[0.0], np.cumsum(y ** 2)[:-1]])

 179  def herding_order(features: np.ndarray, k: int) -> list[int]:
 180      """Herding with the rule of benchmark/Methods/Herding: step t adds the unchosen row minimizing
 181      ||(running sum + x_i) / t - mean||, computed as ||x_i||^2 - 2 x_i (t mean - running sum)."""
 182      X = np.asarray(features, dtype=np.float64)
 183      X = X.reshape(X.shape[0], -1)
 184      n = X.shape[0]
 185      k = min(int(k), n)
 186      target = X.mean(axis=0)
 187      sq = np.einsum("ij,ij->i", X, X)
 188      running = np.zeros_like(target)
 189      chosen = np.zeros(n, dtype=bool)
 190      out: list[int] = []
 191      for t in range(k):
 192          d = sq - 2.0 * (X @ ((t + 1) * target - running))
 193          d[chosen] = np.inf
 194          i = int(np.argmin(d))
 195          out.append(i)

 197          running += X[i]

 202      """Farthest-first traversal with the rule of benchmark/Methods/KCenter: the first row drawn by
 203      default_rng(seed), then the row farthest (Euclidean) from the chosen rows, first index on ties."""
 204      X = np.asarray(features, dtype=np.float64)
 205      X = X.reshape(X.shape[0], -1)
 206      n = X.shape[0]
 207      k = min(int(k), n)
 208      if k == 0:
 209          return []

 211      start = int(np.random.default_rng(seed).integers(n))
 212      out = [start]

 214      available[start] = False
