CARVEPrep 到底做了什么，新在哪里

一句话TabPFN 这类表格基础模型在任务表上做后训练时，每条训练记录既参与参数更新，又在预测时被当作上下文。CARVEPrep 给每条可疑记录分配四种动作之一，保留、修复、删除或降权。每种动作的价值靠“自己往表里注入错误、看准确率怎么变”学出来，不需要真值。最后只有短程后训练证明整张准备好的表比原表好，才采用它。

依据 v20260925 中文稿（ICLR 2027 投稿稿件）。本节讲论文本身，后面各节讲代码怎样实现、和论文哪里不一样。

1　要解决什么问题

TabPFN 依据上下文里给出的带标签样本来预测，后训练在任务数据上微调它的参数，同时保留这种上下文预测方式。所以一条训练记录会从两条途径影响模型，一是进入梯度更新，二是被放进预测新查询时用的上下文。准备一张含错的表，实际上就是在给每条记录分配一个数据动作。

四种动作的含义用“取值”和“权重”两个维度来定义。

动作取值权重 w效果
保留不变1错误也一起留下
修复改写指定单元格1唯一会写入取值的动作，可以和降权组合
删除不变0记录连同有用信息一起退出训练和上下文
降权不变0 到 1 之间保留记录，但降低它在损失和上下文抽样中的比重

论文有两个动机发现（图 1b）。

  • 发现 1。在真实的 Flights 数据上，真值修复即使额外用了 252 条完全干净记录的真值，准确率只有 43.89%，而一个动作分配策略达到 57.22%。数据层面更正确，不等于模型更好。
  • 发现 2。在 Beers 上，只调训练规则让准确率变化 −0.84 个百分点，只做数据准备是 +0.50，两者一起做是 +2.83，交互量 +3.17。训练规则的收益在数据准备前为负、准备后为正，数据准备和模型调优要一起决定。

2　难点在哪

  • 错误证据决定不了最优动作。依赖违反能标出不一致的取值，却判断不了修复、删除还是降权对模型更有利。只看标签和预测的分数又会漏掉一类错误，比如从本列随机重抽的取值，它不改变标签和预测的联合分布。
  • 动作之间有交互，分配空间难搜。可能的分配随记录预算指数增长，而且收益不可加，因为所有记录共同决定训练更新和预测上下文。对动作单独排序，选不出最好的整套方案。
  • 下游比较又贵又有噪声。每个候选都要做一次模型适配，没法穷举后训练。测到的增益受训练随机性和评估样本有限的影响，还要能判断“什么都不做”才是最好的情况。

创新 2

两类证据通道，互相补盲

结构通道读表本身。对依赖 A→B，按 A 分组，组内最高频的 B 值支持度足够时，标出不一致的单元，并把多数值当修复候选。再加缺失、值域、拼写检查。预测通道检查标签，标签在参照模型下的概率不超过其边缘概率时判为标签被否定。

命题证明，只读标签和预测的规则召回率有上限，而结构证据能找到这类错误。实验里在组规模大于 1 的依赖上，结构证据的召回为 0.947，标签条件评分只有 0.184。

创新 3

不用真值学出每种动作的价值

每次试验在工作表的一部分里额外注入错误，对随机选的一个子集 T 施加某种动作，测留出记录上 ICL 准确率的变化 Δ。T 里每条记录的回归目标都是 Δ|T|。每种动作训练一个 LightGBM 回归器，输入是 17 维记录状态。

回归器给每条记录预测“这个动作大概值多少”，在预算内为每条记录选估计正增益最大的动作，没有正增益就保留。整个过程不读取任何真值。

创新 4

动作逐条决定，采纳整表决定

候选包括各清洗比例下的分配、统一策略、先验引导策略、Ref. likelihood 和 RHO-LOSS 两种选择策略、选择后修复，以及原表 NoFix。先用参照集上的 ICL 准确率粗筛，前几名再做重复的短程后训练，和 NoFix 做配对 bootstrap，增益超过间隔且胜出概率 ≥0.9 才采纳，否则保留 NoFix。

理论说明了为什么要这样分工。对可分离的加权最小二乘，逐条收益可加，扩大动作集合的价值能精确算出。但记录一旦共用预测，收益就不可加了，论文给出一个例子，单独删除和单独修复都让风险变大，两个一起做风险降为零。TabPFN 正是共用上下文的模型。

创新 5

数据准备和后训练交替进行

采纳之后，每条记录从上下文里拿掉时的损失，更新它在下一轮的先验。更新后排名最高的记录被当作标签被否定，于是后续轮次能发现单元格通道标不出来的标签错误。每一轮都从原表和初始模型重新开始，上一轮的表作为候选参加比较，只有实测更好才替换。

模型反馈用了两次，一次决定是否采纳，一次更新记录的优先级。实验里反馈回路把 Hospitals 的准确率从 0.8533 提高到 0.9000。

4　方法按步骤走一遍

  1. 划分数据从干净数据划出工作表并注入混合错误（缺失、拼写、依赖违反、标签噪声，每类按 ρ=0.4 注入），另有一个小的干净参照集（用于先验拟合、候选比较、早停，不参与最终梯度更新）和测试集。
  2. 收集证据结构通道和预测通道给每个单元打证据层级，给出经验证的候选修复值和每条记录的参照先验。
  3. 学动作价值在工作表上反复做“额外注入 → 对子集施加动作 → 测 ICL 准确率变化”，训练修复、删除、降权三个回归器，保留的价值记为 0。
  4. 预算内分配按“标签被否定的在前，其余按证据层级加先验”排序，在前 ⌈c·n⌉ 个位置里给每条符合条件的记录选估计正增益最大的动作。标签被否定的删除，修复没有经验证取值的转为降权，修复后仍有疑点的修复并降权。
  5. 两阶段采纳加入各种对比候选，ICL 粗筛，短程后训练细比，配对 bootstrap 决定采纳谁。
  6. 后训练与反馈在采纳的表上后训练。权重同时作用在查询损失（乘以权重）和上下文抽样（按权重抽）上。留出损失更新先验，进入下一轮。

5　理论结果，一句话版

结论它保证了什么成立的前提
命题（动作覆盖）保持记录身份和列结构、权重在 [0,1] 内的任何准备方案，都能写成四种动作的一个分配。生成新记录、权重大于 1 的不在范围内。
命题（只看预测的检测有上限）只读标签和模型预测的检测规则，召回率不超过“挑选比例 + 一个总变差项”。对边缘重抽的错误，即使贝叶斯最优模型下这一项也可能为 0，而结构多数值仍能找出全部被改的单元。多数值的保证要求决定属性没坏、错误率低于门槛 q*。
定理（预算内的精确动作优势）对可分离的加权最小二乘，至多 b 次干预下的最小超额风险等于原风险减去前 b 大的逐条风险下降。去掉修复或分数权重会严格变差，并且在小扰动下仍然成立。每条记录各自决定一个预测方向，锚点固定。
命题（动作交互）存在一个例子，删除三条标签错误的记录和修复另一条记录的特征，单独做都让风险变大，一起做风险为零。记录共用一个预测方向。
命题与推论（独立验收）采纳总体上比冻结参照差 ε 以上的方案的概率 ≤δ₂。有独立无标签样本估计分歧时，可迁移到重训模型。整个评分函数（含预处理）先冻结，验收样本独立同分布。

7　读完自测

为什么不能把每条记录的动作收益加起来，选总和最大的方案？

TabPFN 依据整个加权上下文做预测，记录共用预测，收益不可加。论文的交互例子里，单独删除和单独修复都让风险变大，合在一起风险为零。所以动作逐条提，整张表实测后再决定采不采纳。

动作价值回归器的训练目标为什么是 Δ 除以 |T|？

一次试验只能测到整个子集 T 施加动作后的总变化 Δ，无法单独测每条记录。把 Δ 平均分给 T 里每条记录，再靠大量不同子集里不同的特征组合，训练出能逐条预测的近似模型。

降权和删除有什么不同？

删除让记录完全退出训练和上下文，降权保留它，只降低它在查询损失里的权重和被抽进上下文的概率。降权适合“有疑点但也有用”的记录。

采纳检验为什么不只看平均增益？

平均增益受训练随机性和参照样本有限的影响。配对 bootstrap 还要求增益为正的重采样比例达到 0.9，离散程度大的候选即使平均增益高也可能不被采纳。

普通流程的采纳有统计保证吗？

没有。普通流程在同一个开发参照集上搜索又比较。只有 Cert 变体在独立验收样本上做投注检验，才有命题给出的概率保证。

先把三个问题分开

这个值可能是错的吗？

结构依赖、缺失、格式、拼写、数值异常和标签的条件概率，都能提供“可疑”的证据。

输出是证据，不是动作。

这条记录该怎么处理？

在预算内，按估计出的动作价值选修复、删除或降权，三者都没有正价值就保留。

输出是一张候选准备表。

处理完之后模型真的变好了吗？

先用 ICL 粗筛，再用短程后训练细比。整张表通过采纳检验，才会成为最终的训练输入。

输出是所选策略和模型。
“错误更少”和“后训练效果更好”是两个目标。删掉疑似错误的行，可能也丢了覆盖。修好某些特征，错误的标签可能还留着。CARVEPrep 用下游准确率来判断一整套准备方案值不值。

公式和算法的白话说明

整个问题是在一张含错的表上，为每条可疑记录挑一个动作，让模型在处理后的表上后训练完，准确率尽量高。动作由两件事决定，即取值改不改、权重 w 取多少。

动作取值权重 w
保留不改1
修复改成经验证的候选值1
删除不改0
降权不改0 和 1 之间
修复加降权改0 和 1 之间，只算一次干预

单轮目标是下面这个带约束的最大化。

maxπ Perf(M; Dπ)　约束　|I(π)| ≤ b，RepairError(π) ≤ α，Σi wi > 0

π 是一个分配方案，Dπ 是按它处理后的表，Perf 是后训练模型的准确率。|I(π)| 是被改动的记录数，上限 b = min{K, ⌈c·n⌉}，其中 K 是可疑记录数，c 是清洗比例，n 是总记录数。RepairError 是被改的单元里改错的比例，上限 α。最后一条要求不能把整张表删空。

多轮目标把“准备、训练、反馈”重复 R 轮，再从中选第 r* 轮的表重新训练最终模型。最大化的是最终模型的期望准确率，约束是各轮代价加最终训练代价不超过总预算 B。

max E[Perf(Mfinal(Dr*))]　约束　Σr=1..R costr + costfinal ≤ B

见证规则用来给出修复候选。对函数依赖 A→B，把 A 取值相同的记录分成一组。组内记录数达到下限、严格多数记录取同一个 B 值、而这条记录的 B 不等于它，就称这一组是这条记录的有向见证，多数值就是修复候选。组内有分歧但没有严格多数，就是无向见证，只说明有错，不给候选。

依赖通道给出修复候选要同时满足三个条件。设一组内某列非缺失取值共 ng 个，最高频和次高频的次数是 c1 和 c2。

三个条件依次要求最高频值是严格多数、占比够高、领先次高频值足够多。如果这条记录的决定属性 A 本身被别的通道标为可疑，依赖候选会被撤回，因为分组本身可能就分错了。

标签通道给每条记录一个先验分数，衡量“在这些特征下，这个标签出现得有多反常”。

si = clip( log p(yi)p(yi | xi), 0, log C )log C

p(yi) 是标签的整体频率，p(yi | xi) 是参照数据估计的、在这些特征下出现该标签的概率。后者越小于前者，分数越高，最后截断并归一化到 0 到 1，C 是类别数（至少取 2）。举例取二分类，p(y) = 0.5，p(y | x) = 0.1，比值为 5，log 5 超过 log 2 被截到 log 2，分数为 1。若 p(y | x) = 0.4，分数为 log 1.25log 2 ≈ 0.32。当 p(y | x) ≤ p(y) 时，标签规则标记这条记录。

公式和算法的白话说明

这一节回答“只看模型预测的检测器最多能查出多少依赖违反”。设违反的比例是 ϑ，检测器读到的信息是 Z，δZ 是有违反和无违反两种情况下 Z 的分布差异（总变差距离，0 表示完全一样）。检测器最多挑出比例 ϱ 的单元时，召回率满足下面的上界。

Recall ≤ min{ 1，ϱϑ，ϱ + (1 − ϑ) · δZ }

当 δZ = 0 时，召回率不超过 ϱ，和随机挑一样。论文构造了一个例子，用边缘重抽制造的依赖错误让最优预测模型的输出完全不变，所以模型信号查不出来，但组内多数值能识别出全部被改的单元。这说明结构证据和模型信号看到的是不同的错误。

多数值什么时候可靠由下面的容忍度决定。

q* = min{ 12，1 − rmin，1 − mmin2 }，　要求错误率 ρ < q*
真值是唯一多数且通过两个阈值的概率 ≥ 1 − exp( −m · kl(q* ‖ ρ) )

m 是组的大小，kl 是两个伯努利分布之间的相对熵。组越大、错误率离 q* 越远，概率越接近 1。举例取 rmin = 0.6，mmin = 0.2，则 q* = 0.4。错误率 ρ = 0.1 时，10 条记录的组下界约为 0.956，20 条记录的组约为 0.998。

标签规则的含义由错标后验给出。设重抽概率为 ρ，q = p(y | x)，b = p(y)。

P(标签错 | x, y) = ρ · b · (1 − q)(1 − ρ) · q + ρ · b

q 越小，错标后验越高。举例取 ρ = 0.2，b = 0.5，q = 0.1 时后验为 0.5，q = 0.6 时后验约为 0.07。CARVEPrep 用 qb 的参照估计给记录排序。

这一节在一个能精确求解的模型上算出“多一种动作到底值多少”。模型是加权线性回归，每个方向 j 上有一条固定的锚定记录和一条可干预记录。可干预记录的特征是 z·vj，标签是 y，权重是 w。拟合出的预测只和这一条记录有关。

qj = w · z · yaj + w · z2

aj 是锚定记录的强度。总体风险是各方向预测与真实条件均值 tj 的加权平方距离。记 hj 为只改第 j 条记录时风险最多能降多少。

最小风险(b) = 原表风险 − (最大的 b 个 hj 之和)

因为每条记录只影响自己的预测坐标，各条记录的降幅可以直接相加，所以在预算 b 下挑降幅最大的 b 条就是最优解。动作集合越大，每个 hj 越大，优势可以精确算出。

第一个命题说明四种动作覆盖了所有“不增删记录、权重在 0 到 1 之间”的准备方法。每条保留下来的记录只有两个独立选择，即取值改不改、权重是不是 1，组合出保留、修复、降权、修复加降权四种情况，权重为 0 就是删除。插补、标签纠正、子采样、重要性加权都能写成这几种动作的分配。

|Πb| = Σj=0..b C(K, j) · qj

κ0 是原表的残留错误，Tb 是错误最多的 b 条记录里的错误单元总数。改 b 条记录最多消掉这么多错误，有效覆盖最低降到 n − bn。删除错误最多的 b 条记录能同时达到这两个下界。

普通流程在同一个开发参照集上既搜索又比较，通过 bootstrap 不足以证明在所有新数据上都不会变差。Cert 变体先用开发部分冻结候选和评估模型，再在独立的验收样本上，对配对分数做投注式 e-process 检验，门槛是候选数 K/δ。论文的保证针对冻结的模型，在独立同分布等假设下，控制“总体上比基准差超过 ε 却被采纳”的概率。

最终重训出来的模型不是那个冻结的实例，要把保证迁移过去，还需要控制两者在独立样本上的预测分歧。主表的 Cert 行留出 40% 的参照集，并且加入了 Jellyfish 候选，所以它和普通 CARVEPrep 的区别不只是换了一个检验公式。

降权具体怎样作用到 TabPFN 后训练里

在查询损失上乘以权重

L = Σᵢ∈Q wᵢ CE(M(xᵢ), yᵢ) / Σᵢ∈Q wᵢ

Q 是这一步训练抽出来的 query 记录。权重低的行对参数更新的贡献小。按权重归一化的分母，可以避免大量降权把梯度的尺度随意缩小。

按权重抽样进上下文

P(i 进入 context) ≈ wᵢ

没有被抽成 query 的记录，按 wᵢ 的概率被抽进 context。实现还会给每个类别补足最少的上下文记录，默认 2 条，所以最终入选的记录并不是严格独立的 Bernoulli(wᵢ)。

只降低查询损失是不够的。一条可疑记录就算对梯度贡献不大，也可能作为完整的上下文证据去影响其他查询。主实验的权重设计在这两个位置同时起作用。

反馈闭环更新的是优先级，并不是一轮接一轮不可撤回地清洗

pᵣ₊₁ = (1 − β)pᵣ + β Normalize(ℓᵣ)，β 默认0.5

每轮训练完，把某条记录从上下文里拿掉后的损失当作反馈。有损失的行更新先验，被删掉的行这一轮没有损失，凸合并模式下沿用旧先验。下一轮重新读入 D₀ 和 M₀，之前被删掉的记录还可以重新参与动作分配。

主要公式逐项解释，先弄清它在算什么

① 标签先验和“实际错标”不是同一个概率
sᵢ = clip(log[bᵢ/qᵢ], 0, log C) / log C
qᵢ = p(yᵢ|xᵢ)，bᵢ = p(yᵢ)，C ≥ 2

q 高于边缘概率 b 时，对数比值 ≤0，先验被截成 0。q 很低时先验接近 1。它是归一化后的不可信程度，不是出错概率。部署时标签否定的条件是 q≤b，相等时也会被标出来。

d = (1−ρ)q + ρb
P(触发重抽 | x,Y=y) = ρb/d
P(实际错标 | x,Y=y) = ρb(1−q)/d

重抽有可能刚好抽回真实标签，所以第二个式子多了一个 (1−q)。成本对称时，严格的 Bayes 删除条件是 (1−ρ＋2ρb)q≤ρb。论文没有把默认的 q≤b 说成这条需要知道 ρ 的最优规则。

② 预算约束、修复风险和总成本
I(π) = {i : zᵢ ≠ 原配置 或 wᵢ ≠ 1}
|I(π)| ≤ min(K, ceil(fn))，RepairError(π) ≤ α，Σwᵢ > 0

K 是允许干预的记录数，n 是工作表的行数。同一行既修复又降权只算一次。这个公式是问题定义，部署时算法只能用手头的证据近似控制修复风险，它没有查真值去检查每个候选是否满足 α。完整的外部或对比候选还可能超出 CARVEPrep 自己的分配预算。

Σᵣ costᵣ + costfinal(r*) ≤ B

B 是时间或计算的总预算，包括证据、候选评分、训练、反馈和最后的重训，不能只数改了多少个单元格。

③ 质量坐标，以及它们的不足
κ = [Σᵢ wᵢ × 该行仍错误的单元数] / (n d)
η = (Σᵢwᵢ)² / [n Σᵢwᵢ²]

κ 需要真值，η 只需要权重。κ 的分母固定为原表的 nd，所以删掉错误行就能让 κ 下降，即使一个值也没修好。等权保留 m 行时 η=m/n。所有正权重同乘一个常数，η 不变，所以 η 反映的是相对权重下的有效样本量，并不能完整衡量绝对的训练质量或类别覆盖。

κ、η 相同的两张表，在保留了哪些记录、标签关系和训练规则上仍可能不同，不能单凭平面坐标推出准确率。

④ 排序和动作价值是两个不同的任务
Tᵢ = Σⱼ tierᵢⱼ，c=2d+1
T̃ᵢ = 标签否定 ? (2c+c sᵢ) : Tᵢ
rankᵢ = N(10T̃ + N(s))ᵢ

N 表示在表内做 min-max，常数向量映射为 0。rank 只决定谁先拿到预算，同时控制降权曲线。17 维 state 里的 tier_max 和 tier_sum 是回归器的输入，真正决定采取哪类动作的是动作价值 V。两者不能互相替代。

当前附录写明了按求和排名以及同分时的顺序。正文 state 定义里的“最大层级”和实现中的“求和”用途不同，不应理解为算法前后没同步。

⑤ 检测能看到的信息有上限，以及多数值恢复的界
RecallZ(ϱ) ≤ min{1, ϱ/ϑ, ϱ+(1−ϑ)δZ}
q* = min{1/2, 1−rmin, (1−mmin)/2}
P(组真值多数且过门槛) ≥ 1 − exp[−m kl(q*‖ρ)]，0<ρ<q*

ϱ 是检测器最多能挑的比例，ϑ 是实际违反的比例，δZ 是错误输入和正常输入两类信息分布之间的总变差。如果预测信息和错误无关，δZ=0，召回率就超不过挑选比例。结构通道读了额外的信息，所以能突破只看预测的那个界。

多数值的界要求四个前提，依赖在干净数据上严格成立、决定属性没有被污染、参与比较的值都不缺失、完整的组事先固定。位置固定、不放回抽样时，论文另外给了超几何尾概率，两种采样方式不能混为一谈。

⑥ 有限的策略空间为什么会这么大
qᵢ = mᵢ (|Wᵢ|−1)
|Πb| = Σⱼ₌₀ᵇ [tʲ] Πᵢ∈S(1+qᵢt) − 1{K=n=b}

mᵢ 是包括原值在内的可用配置数，Wᵢ 包含 0 和 1。删除时取值是什么都一样，只算一种。再减掉“全部删除”这一种，保证 Σw>0。如果每行有原值和一个修复值，权重可取 0、0.5、1，那么每行有 5 种不同结果，其中 4 种算干预，q=4。预算为 3、K=8 时，共有 1＋8×4＋28×16＋56×64=4065 种策略，这还没加修复风险约束。

撤回到 NoFix 总能保持可行，但要先撤回错误率最高的修复记录。如果先撤掉修得对的，剩下修复的错误比例反而可能升高。算法并不穷举这个空间，只构造一个较小的候选集合。

理论可以直接算出来，四种动作什么时候严格更好

论文里的解析构造，不是 TabPFN 上的测量 每个方向有一条固定的锚点记录和一条可干预记录，共 8 条记录。锚点保证最小二乘解唯一，4 个预测方向相互独立。

qⱼ(z,y,w) = wzy / (aⱼ + wz²)
hⱼ = pⱼ[(qⱼ⁰−tⱼ)² − dist(tⱼ,Sⱼ)²]
R*menu(b) = R(q⁰) − Topb(h)

aⱼ 是锚点强度，pⱼ 是这个方向在总体中的概率，tⱼ 是总体的目标均值，Sⱼ 是这份动作菜单能达到的预测值集合。修复增加了预测的端点，连续降权填满了从 0 到端点之间的区间。只有方向相互独立时，Top-b 才精确成立。

严格分离、微扰和质量包络各自证明了什么

当特征每行的欧氏扰动 ≤0.001、目标均值的无穷范数扰动 ≤0.01，并且标签、配置对应关系和预算都不变时，论文给出受限菜单和完整菜单之间至少 1/288 的差距。证明靠的是正规矩阵的扰动界，并不保证任意大的扰动或任意神经网络模型也成立。

κ₀−Tb/(nd) ≤ κ ≤ η；max(n−b,1)/n ≤ η ≤ 1

Tb 是可干预记录里原始错误单元数最大的 b 个之和。这个界限制了质量坐标能到达的范围，但它不告诉你哪张表的后训练准确率最高。

共用一个预测方向时，动作的收益会互相影响

原来的两类错误部分相互抵消。只纠正其中一类，另一类的偏差就暴露出来。由公式 I=Δ(删除＋修复)−Δ(删除)−Δ(修复)=57/196 可见，把每个子操作的增益分别测出来再相加，会得到错误的结论。
