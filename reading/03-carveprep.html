\begin{abstract}
表格基础模型（如 TabPFN）在任务表上进行后训练，其中每条记录既参与参数更新，也作为预测时的上下文。因此，准备一张含错的表，实际上是在为每条记录分配数据动作。检测到错误并不说明修正它会改善模型，各动作的效果也未必可加，所以这些决定应由训练后的模型判断，而不是由数据是否正确来判断。本文提出 CARVEPrep，它依据依赖违反与标签检查标出错误，在不使用真实取值的情况下，用自身注入的错误训练预测器来为每条记录选择动作，并且只有当重复短程后训练表明准备后的表优于未处理表时才采用它。训练后模型的反馈随后为下一轮重新排定记录优先级。本文证明，在改动记录数相同的预算下，去掉修复或部分权重可能使效果严格变差。在\num{F2 datasets}张注入错误的表上，CARVEPrep 的平均准确率为 \num{F2 carveprep reported accuracy}，未处理数据为 \num{F2 nofix reported accuracy}，\num{F2 baselines}种对比方法中最强者为 \num{F2 best baseline reported accuracy}，后者改写的单元数是 CARVEPrep 的 \num{F2 cells ratio} 倍，而 CARVEPrep 在六张表中的四张上不逊于任何对比方法。配合各数据类型自身的证据，同样的数据动作可以迁移到传感器时序数据，在六个故障工况中的五个上排名第一，也可以用于 Qwen2.5-1.5B 的指令微调，使留出损失从 \num{F8 text nofix nll} 降至 \num{F8 text heldout nll}。同时调整数据与后训练超参数，在 \num{Arms tasks} 个任务中的 \num{Arms tasks joint best} 个上不逊于只调整其中一侧。
\end{abstract}

\section{引言}
\label{sec:intro}

\textbf{数据准备决定了模型能从任务表中学到什么。}
错误若不修复，会改变模型学到的关联，而删除含错记录又会连同错误一起丢弃有用的观测~\citep{zha2023datacentric}。
对表格基础模型而言，决定哪些记录修复、删除或保留，会从两条途径影响模型。
TabPFN 依据上下文中给出的标注支持集进行预测~\citep{hollmann2025tabpfn}，后训练在任务数据上微调其参数，同时保留这种上下文预测方式~\citep{rubachev2025finetuning}。
因此，每条训练记录既进入参数更新，也进入预测新查询时使用的上下文。

实践中，更好的数据可以带来模型调优得不到的收益~\citep{jarrahi2023datacentric,jakubik2024datacentric}。
在一个钢缺陷检测案例中，仅清洗数据就使准确率从 76.2\% 升至 93.1\%，而修改模型没有带来提升~\citep{ng2021datacentric}。
然而，自动修复可能引入新错误，数据层面正确性的提高也未必带来更好的预测~\citep{ni2024automatic,rein2023}。
数据准备与训练也相互耦合。降权在保留取值的同时降低记录在损失与上下文中的占比，而最优的训练规则也会在数据准备后改变。
因此，数据准备的目标是\emph{在准备后数据上训练所得模型的性能}。

\textbf{向记录分配动作是数据与模型的联合决策。}
修复改变取值，既可能恢复正确取值，也可能写入错误候选。删除与降权作用于记录权重。删除使记录连同其有效信息一起退出训练与上下文，降权以较低的影响程度保留该记录。保留使取值与权重都不变，错误也一并留下。
同一动作可能帮助一条记录而损害另一条，因此改进一张表需要决定\emph{何处修复、何处降低影响，以及何处保持不变}。

图~\ref{fig:motivation}(b) 说明了为什么必须通过模型反馈这种动作分配。
\textbf{发现 1.} 与动作分配策略相比，真值修复即使额外使用 252 条完全干净的记录真值，准确率却更低（43.89\% 对 57.22\%）。\textbf{发现 2.} 单独选择训练规则会降低准确率，单独准备数据会提高准确率，
而在准备后的表上选择训练规则可进一步提高准确率。
因此，训练规则选择的边际收益可能因数据准备而改变，产生了正交互，而不是独立收益的简单求和。
这两个发现说明，以数据为中心的改进与模型调优同样重要，而改进的关键在于如何为记录分配动作，其效果只有通过模型反馈才能判断（附录~\ref{app:motivation}）。

\Needspace{5\baselineskip}
\textbf{挑战。}模型感知的数据动作分配面临三项困难。

\textbf{(1) 错误证据不能确定最优动作。}
依赖违反能标出不一致的取值，却无法判断修复、删除还是降权对模型更有利。
预测分数提供任务信息，但可能漏掉不改变标签与预测联合分布的错误，例如从本列随机重抽的取值。
决策需要把这些信号与每种动作对模型的实际作用联系起来。

\textbf{(2) 动作交互使分配空间难以搜索。}
即使动作数固定、权重集合有限，可能的分配也会随记录预算指数级增长，且各动作的收益未必可加，因为记录共同决定训练更新与预测上下文。
因此，对动作独立排序无法确定最好的完整准备方案。

\textbf{(3) 下游比较代价高、结果有噪声，且依赖具体模型。}
每个候选都需要模型适配，因此无法穷举后训练，而测得的增益又受训练随机性和有限评估样本影响。
候选越多，留给可靠比较的预算就越少。
流程需要决定哪些候选值得训练，以及何时已有足够证据替换未处理表，也要覆盖任何干预都无益的情形。
它还需要迁移到证据与评价指标都不同的其他下游模型和数据类型上。


\textbf{贡献。}本文提出 \sys{}，它标出错误、为每条记录决定动作，并由下游模型的反馈选出完整准备方案（流程见图~\ref{fig:motivation}(a)）。

\textbf{(1) 将数据准备建模为预算下的动作分配。}
本文将数据准备表述为在记录预算下分配保留、修复、删除与降权动作。
这一设计只依赖记录取值与权重，因此可以迁移到其他模型与数据类型。
针对一类可分离加权最小二乘学习器，本文精确计算动作集合在预算内能带来的收益，并给出一个在小扰动下仍成立的实例，其中去掉修复或分数权重会严格抬高最小风险（定理~\ref{thm:budgeted-action-advantage}、命题~\ref{prop:weighted-separation}）。
本文还证明，只依据标签与预测的检测方法可能漏掉依赖检查能发现的错误（命题~\ref{prop:interface-limit}）。

\textbf{(2) 无需真实取值即可学习的逐记录动作决策。}
每种动作训练一个回归器，训练数据来自在工作表中额外注入的错误，回归器预测每条记录在该动作引起的上下文学习准确率变化中所占的份额，从而为每个清洗比例生成一个分配（第~\ref{sec:allocation}~节）。
上下文学习筛选在后训练之前缩小候选集。
回归器逐条记录决定动作，而保留哪个方案由整个准备方案的准确率决定，因为本文证明动作之间可能存在交互，并给出一个实例，其中一次删除与一次修复各自都会抬高风险，合起来却能消除风险（命题~\ref{prop:action-interaction}）。

\textbf{(3) 由模型反馈驱动的数据与模型联合调优。}
重复短程后训练将各候选与未处理表比较，只保留通过采纳规则的候选。
训练后模型的留出损失随后为下一轮重新排定记录优先级（第~\ref{sec:cooptim}~节）。
这一反馈只需要实测分数，因此也适用于其他模型与评价指标。
在独立的验收样本上，留出变体控制采纳比未处理表差出一定幅度以上的准备方案的概率，重训之后同样成立（命题~\ref{prop:acceptance}、推论~\ref{cor:final-fit-transfer}）。

\paragraph{(4) 跨数据规模、数据类型与下游模型的实验证据。}
在\num{F2 datasets}张注入错误的表上，\sys{} 的平均准确率为 \num{F2 carveprep reported accuracy}，未处理数据为 \num{F2 nofix reported accuracy}，\num{F2 baselines}种对比方法适配中最强者为 \num{F2 best baseline reported accuracy}，后者改写的单元数是 \sys{} 的 \num{F2 cells ratio} 倍。
\sys{} 在六张表中的四张上不逊于任何对比方法，并在至多 \num{Scale adult largest pool} 条记录的 Adult 数据池上始终高于 NoFix，领先 \num{Scale adult nofix gain min pp} 到 \num{Scale adult nofix gain max pp} 个百分点。
在相同的四类动作与各数据类型自身的证据下，它在六个传感器时序故障工况（TEP）中的五个上排名第一，并在以大语言模型作为下游模型时，将 Qwen2.5-1.5B 在 Alpaca 指令数据上的留出损失从 \num{F8 text nofix nll} 降至 \num{F8 text heldout nll}。
同时调整数据与训练规则，在 \num{Arms tasks} 个任务中的 \num{Arms tasks joint best} 个上不逊于只调整其中一侧（表~\ref{tab:main}）。

\section{问题定义}
\label{sec:problem}

给定含 $n$ 条记录、$d$ 列的错误数据表 $D_0$、依赖集合 $\Sigma$，以及带性能度量 $\mathit{Perf}$ 的下游模型 $M$。目标是在记录预算下为每条记录分配数据动作，使 $M$ 在准备后的表 $D_\pi$ 上完成后训练后，性能尽可能高。这里 $\mathit{Perf}$ 指后训练模型的总体准确率，搜索阶段在参照集上估计，报告结果时在干净测试部分上估计，因此每个分配都由模型反馈而不是数据是否正确来评判。

\begin{definition}[可疑记录集]
\label{def:errorspace}
令 $S\subseteq\{1,\ldots,n\}$ 为证据或选择规则允许干预的记录下标集合，$K=|S|$。记录 $r_i$（$i\in S$）的证据表示为 $\langle \tier_i, \sFM_i, \sDB_i, \mathit{cand}_i \rangle$，其中 $\tier_i=\max_j\tier_{ij}$ 为其各单元证据层级 $\tier_{ij}$（定义~\ref{def:witness}）的最大值，$\sFM_i$ 为其逐记录先验分数，$\sDB_i=(\sDB_{ij})_{j=1}^d$ 为其各单元的结构证据，$\mathit{cand}_i$ 为其各单元的经验证候选取值。
\end{definition}

\begin{definition}[四类动作]
\label{def:four-action}
四类数据动作为 $\Aset=\{\aret,\arep,\adel,\adwn\}$。保留保持取值并设 $w_i=1$，修复改变指定单元取值并设 $w_i=1$，删除设 $w_i=0$，降权保持取值并设 $0<w_i<1$。修复可与降权组合，也是唯一写入取值的动作，因此是修复错误的唯一来源。对于保持记录身份与列结构且权重在 $[0,1]$ 内的准备方案，这些原语能够表示其全部输出，其中被删除记录的取值不影响等价性（命题~\ref{prop:action-coverage}）。CARVEPrep 将修复限定为经验证的候选配置。
\end{definition}

\begin{definition}[分配策略]
\label{def:policy}
对每个 $i\in S$，令 $\mathcal Z_i$ 包含互不相同的配置，即下标为 $0$ 的原记录及可用的经验证修复。策略为每条可疑记录指定配置 $z_i\in\mathcal Z_i$ 与权重 $w_i\in[0,1]$。其余记录保持原值和权重一。权重为零时采用 $z_i=0$ 的规范表示。被干预集合为 $\mathcal I(\pi)=\{i\in S:z_i\ne0\text{ 或 }w_i\ne1\}$。同一记录的修复与降权组合只计一次干预。
\end{definition}

对 $\cleanfrac,\alpha\in[0,1]$，令 $b=\min\{K,\lceil\cleanfrac n\rceil\}$。目标为
\begin{equation}
\label{eq:objective}
\sup_{\pi}\mathit{Perf}(M;D_\pi)
\quad\text{s.t.}\quad |\mathcal I(\pi)|\le b,\qquad \mathrm{RepairError}(\pi)\le\alpha,\qquad \sum_iw_i>0,
\end{equation}
其中 $\mathrm{RepairError}$ 是被修改单元中修改后取值与真值不符的比例，没有单元被修改时约定为零。记录预算 $b$ 限制一个分配改动的记录数，$\alpha$ 限制其修复出错的比例，因为修复还可能需要获取或核验真实取值，从而产生实际成本。命题~\ref{prop:budget-space} 刻画所得搜索空间，并证明每个可行策略均能经由保持可行的逐记录撤回路径回到原表。命题~\ref{prop:coverage-envelope} 给出其残余错误与有效覆盖的界。该预算作用于 \sys{} 构造的逐记录分配。最终比较还纳入完整的对比准备方案，它们的干预数可以超过 $b$，所有候选都按同一采纳规则评判（第~\ref{sec:allocation}~节）。

\begin{definition}[预算约束下的数据准备与后训练交替过程]
\label{def:cooptim}
数据准备与后训练交替进行，使每个训练后模型的反馈能够进入下一次准备。
第 $r=1,\ldots,R_{\mathrm{loop}}$ 次迭代在先验 $p_r$ 下构造并比较原始表 $D_0$ 的准备方案，得到 $D_r$，随后从预训练模型 $M_0$ 开始后训练得到评估模型
$M_r$，并用上下文留出损失更新下一次迭代的先验。每次迭代的代价 $\mathit{cost}_r$ 包括准备、候选评分、训练和反馈。
选定迭代 $r^\star$ 后，流程按固定的最终训练规则重新训练 $M^{\mathrm{final}}(D_{r^\star})$，
$\mathit{cost}_{\mathrm{final}}(r^\star)$ 包括此次最终训练与评估。目标为
\begin{equation}
\label{eq:cooptim}
\max_{R_{\mathrm{loop}},\;1\le r^\star\le R_{\mathrm{loop}}}\;\mathbb E_{\mathrm{train}}[\mathit{Perf}(M^{\mathrm{final}}(D_{r^\star}))]
\quad\text{s.t.}\quad\sum_{r=1}^{R_{\mathrm{loop}}}\mathit{cost}_r+\mathit{cost}_{\mathrm{final}}(r^\star)\le B.
\end{equation}
其中 $B$ 为总预算，期望以所选准备方案为条件，对最终训练的随机性取。已训练模型实例的 $\mathit{Perf}$ 为其总体准确率，最终模型从不在其训练表上评分。输出由所选准备方案和重新训练的模型组成。每个分配产生一张准备后的表，随后在其上训练。零分配预算下，在未改动的 $D_0$ 上训练。该目标计入每个阶段的代价，实验采用固定迭代轮数与短程训练日程（附录~\ref{app:details}）。
\end{definition}

\textbf{动作空间区分对取值的修改与对影响程度的调整。}

\textbf{证据通道。}动作空间确定后，证据通道把可能出错的单元记为证据层级（定义~\ref{def:witness}）。结构通道直接读取表本身。对依赖 $A\to B$，在 $A$ 上取值相同的记录构成一组。当该组的最高频 $B$ 值具有足够支持度时，与之不一致的单元被标记，并以该值作为修复候选，而没有多数值的组只标记分歧。缺失标记、值域约束与拼写检查标记其余单元。预测通道则检查标签，当一个标签在参照集上拟合的模型下的概率不超过其边缘概率时，该标签被否定（附录~\ref{sec:detection_detail} 与~\ref{sec:label-rule}）。

\emph{两类通道提供不同的信息。}命题~\ref{prop:interface-limit} 把任何只读取标签与模型预测的规则的召回率，限制在选取比例加上一个由其输入在两个条件分布之间的总变差构成的项之内。对于边缘重抽下的依赖，这两个条件分布即使在贝叶斯最优模型下也可能完全相同，而每组未被破坏的多数值仍能识别出全部被改动单元，且多数值出错的概率随组规模指数衰减。两类通道都不能说明对某条记录施加动作会提升后训练模型。因此，阶段二学习每种动作的价值，并且只在模型反馈认可时保留动作。

\textbf{逐记录估计决定动作，完整准备方案的准确率决定是否采纳。}
阶段二分三步把记录状态变成一个准备方案。它先按证据对记录排序，再依据学习得到的动作价值为每条符合条件的记录决定动作，最后只有当后训练测得相对未改动原表的增益时才采纳一个完整准备方案（算法~\ref{alg:carveprep}）。本文称这种分配为联合分配，因为一个动作只有作为完整准备方案的一部分才会被采纳，其效果始终按方案整体度量，因此同一份证据可以在一张表上对应修复，在另一张表上对应不做改动。逐记录决定动作、整体决定采纳的这种分工，源于动作之间的组合方式。

\textbf{为何比较完整准备方案。}
对于附录~\ref{app:capacity} 的可分离加权最小二乘族，定理~\ref{thm:budgeted-action-advantage} 给出在至多 $b$ 次干预下的最小超额风险，等于未准备时的风险减去前 $b$ 大的逐记录风险下降之和，因此扩大动作集合所带来的优势可以精确算出。在相同预算下，修复增加可达预测的端点，分数权重补足删除与这些端点之间的区间。因此，完整集合与缺少其中任一者的集合严格分离，该差距在训练特征与目标均值受到足够小的扰动后仍然保持（命题~\ref{prop:weighted-separation}、推论~\ref{cor:stable-separation}）。该定理中的逐记录下降之所以可加，是因为其中每条记录各自决定一个预测。记录一旦共用预测，下降便未必可加。命题~\ref{prop:action-interaction} 给出一个实例，其中删除三条标签错误的记录与修复另一条记录的特征取值各自都提高超额风险，两者合起来却达到零超额风险。表格基础模型依据整个加权上下文预测每个查询，其训练记录因此共用预测。所以 \sys{} 用逐记录估计决定动作，由完整准备方案的实测准确率决定是否采纳。

\textbf{决定记录动作。}
前两步决定动作。记录按参照条件先验与证据层级相加的分数排序，标签被否定的记录排在最前。在前 $\lceil\cleanfrac n\rceil$ 个位置中，带可疑单元或标签被否定的记录符合干预条件，其余记录予以保留，这在构造上满足式~\eqref{eq:objective} 的记录预算（附录~\ref{sec:ranking}）。标签被否定的记录予以删除。其余每条符合条件的记录接受估计正增益最大的动作，没有正增益时予以保留，所选修复没有经验证取值时转为降权。动作价值在工作表上学习得到，不使用任何真实取值。每次扰动试验在表的一部分中额外注入错误，对随机选取的符合条件子集 $T$ 施加一种动作，并测量留出记录上的上下文学习准确率变化 $\Delta_a(T)$。每条被处理记录以子集平均值 $\Delta_a(T)/|T|$ 为回归目标，每种动作对应一个回归器，依据记录特征学习预测这一目标（附录~\ref{app:method-details}）。

\textbf{由模型反馈决定采纳。}
最后一步采纳一个完整准备方案。候选包括每个清洗比例下的分配、先验引导策略与统一策略、由两种参照选择分数构造的候选，以及未改动的原表。参照集上的上下文学习准确率对它们进行筛选，排在前列的候选按算法~\ref{alg:carveprep} 的规定进行重复短程后训练。它们的逐记录正确率在同一组参照记录上用配对 bootstrap 与未改动的原表比较，该检验还取决于逐记录差值的离散程度，因此平均增益不能单独决定是否采纳。平均增益最大的候选在通过增益间隔与胜出概率水平时被采纳，否则保留未改动的原表。因此，单元改动只有在包含它的准备方案被实测为更好时才会被接受（附录~\ref{sec:bound}）。

\textbf{准确率取决于改动落在何处，而不是改动多少。}
CARVEPrep 比 \num{F2 best baseline label} 高 \num{F2 gain over best baseline pp} 个百分点，弥补了 NoFix 与干净训练之间差距的 \num{F2 headroom recovered}（表~\ref{tab:main}）。在相同数据划分与错误实例上，对三次训练运行全部取平均，CARVEPrep 的准确率为 \num{V12 carveprep mean over seeds}，最强对比方法为 \num{V12 best baseline mean over seeds}，NoFix 为 \num{V12 nofix mean over seeds}（附录~\ref{app:v12}）。
Jellyfish 改写的单元取值数是 CARVEPrep 的 \num{F2 cells ratio} 倍，修复错误率是其 \num{F2 mis ratio} 倍（附录表~\ref{tab:cost}）。然而在 Flights 上，它修改的单元有 \num{f2 jellyfish flights mis pct}\% 与真值不符，这却是它唯一超过 CARVEPrep 的一张表。可见数据层面的正确性与模型准确率会彼此脱节，正如图~\ref{fig:motivation}(b) 中的真值修复，因此 CARVEPrep 依据模型反馈，在 RHO-LOSS 等选择方法产生的删除、修复方案与原始数据之间选择。统一动作也无法在各表之间通用。DeleteAll 在 Flights 动机实验中优于其余统一策略（附录~\ref{app:motivation}），但六表平均准确率在统一策略中最低（表~\ref{tab:main}）。

\textbf{同一准备方案同时改善记录影响模型的两条途径。}
未注入错误时，六张表均选中 NoFix，即干净数据保持不变。从 $\rho=0.4$ 到 $\rho=0.5$，相对 NoFix 的平均增益增长到两倍以上。同一准备方案在每张表上均改善参数适配与上下文预测，当准备后的表作为上下文支持时增益更大（图~\ref{fig:results}(a--e)）。

\textbf{哪种动作有益取决于错误类型。}
\label{sec:regimes}
主比较中选出的准备方案均删除记录，Adult 的方案还修复经验证的特征值。当标签错误存在时，下游比较倾向于移除标签被拒绝的记录，而不是进行不消除标签错误的特征修复。
在相同错误率下，仅有特征错误时，NoFix 接近干净训练，六张表中的三张保持不变（图~\ref{fig:results}(f)）。
标签完好时，测试集上最优的四动作候选在半数表上优于最优的保留与删除候选，Flights 的候选使用分数权重，Tax 的候选组合经验证修复与删除（附录图~\ref{fig:v12}(b)）。这些回顾性比较体现了命题~\ref{prop:weighted-separation} 刻画的动作空间容量，而这一容量能否实现，取决于采纳步骤。

\textbf{逐记录分配与结构证据带来了主要收益。}
\label{sec:ablation}
相对包含 NoFix 与两个选择候选的受限候选集，完整候选集在相同采纳规则下高 \num{Mechanism C minus A pp} 个百分点（附录表~\ref{tab:mechanism}），这一扩展同时增加了记录排序、删除比例与动作选择。在 Beers、Flights、Hospitals 与 Tax 上它采纳 CARVEPrep 的逐记录分配，这四张表贡献了 \num{Mechanism C minus A pp} 个百分点中的 4.20 个。在 Hospitals 上，只加入选择后修复会下降 \num{Mechanism hospitals B minus A pp} 个百分点，而完整候选集提高 \num{Mechanism hospitals C minus A pp} 个百分点，并采纳逐记录分配而非这些修复，因此一个候选的价值取决于菜单中的其余候选，这正是动作效果未必可加时应有的现象（命题~\ref{prop:action-interaction}）。在见证组大小中位数均值大于一的依赖上，结构证据几乎识别出每一处注入的违反，而标签条件评分识别出的不到五分之一（附录~\ref{app:deferred}）。命题~\ref{prop:interface-limit} 对不改变标签与预测联合分布的错误所预言的，正是这一差距。

\textbf{数据准备改变模型调优的价值。}
\label{sec:joint}
表~\ref{tab:main} 的最后一块检验数据与模型联合调优。它将原表与准备表分别和固定训练规则、参照集选定的规则交叉，四种配置均来自同一网格，训练规则按表分别选择。
同时调整两者时，在六张表中的 \num{Arms main joint best cells} 张与全部 \num{Arms tep cells} 个 TEP 工况上取得最优或并列最优。
在 Beers 上，仅选择训练规则使准确率变化 \num{Arms beers model gain pp} 个百分点，数据准备单独使用为 \num{Arms beers data gain pp}，二者合起来为 \num{Arms beers joint gain pp}，交互量 \num{Arms beers interaction pp} 个百分点，如图~\ref{fig:motivation}(b) 所示。
选择训练规则的收益在数据准备前为负，在准备后转为正，体现了数据准备与模型适配之间的局部超可加交互。
附录~\ref{app:dataset-gains} 逐任务比较数据侧与模型侧的增益。

\textbf{反馈使先验更准确，留出验收则选出更好的表。}
\label{sec:certified}
随着迭代进行，更新后的先验在每张表上都把注入的标签错误排得更靠前，使其 AUC 上升（图~\ref{fig:results}(h)），反馈回路还把 Hospitals 的后训练准确率从 \num{E3 single hospitals acc} 提高到 \num{E3 union hospitals acc}（附录图~\ref{fig:v12}(f)）。留出投注规则在六张表中的 \num{E5 cert_split adopted} 张上选出准备方案。把 Jellyfish 的准备表加入候选后，该规则在它更强的 Flights 上选择该表，而在 Hospitals 与每个 TEP 工况上仍选择 CARVEPrep 的候选（附录图~\ref{fig:v12}(g)），且 CARVEPrep-Cert 以 \num{F2 cert mean} 在 21 个非先知方法中排第二（表~\ref{tab:main} 的 CARVEPrep-Cert 行）。

\textbf{混合动作的优势延伸到表格之外与 TabPFN 之外。}
TEP 含 52 个传感器特征，未声明依赖。动作分配使用序列特有证据、参照先验与价值模型，在六个工况中的五个上排名第一（表~\ref{tab:main}）。在 Alpaca 上，下游模型换成大语言模型 Qwen2.5-1.5B-Instruct，证据来自近重复见证、格式规范化与截断检测。采纳的准备方案仍然混合使用多种动作，平均修复 756 条、删除 1,050 条、降权 128 条记录，留出损失为 \num{F8 text heldout nll}，按参照损失删除同等条数时为 \num{F8 text best deletion nll}，统一策略为 1.378 至 1.388，NoFix 为 \num{F8 text nofix nll}（附录~\ref{sec:exp-operators}）。

\section{结论}\label{sec:conclusion}

\textbf{\sys{} 把为基础模型准备数据看作一个动作分配问题，并由模型本身来评判。}改动落在何处，比改动多少更重要。在\num{F2 datasets}张表上，采纳的准备方案平均准确率为 \num{F2 carveprep reported accuracy}，比最强对比方法高 \num{F2 gain over best baseline pp} 个百分点，而后者改写的单元数是其 \num{F2 cells ratio} 倍，与此同时，正确的真值修复仍可能降低准确率。合适的动作取决于错误类型，结构证据能找到预测遗漏的错误，而且动作之间存在交互。可分离加权最小二乘分析精确给出每个动作集合在预算内的收益，并表明去掉修复或分数权重可能使效果严格变差。数据与模型的决策同样相互耦合，同时调整两者在 \num{Arms tasks} 个任务中的 \num{Arms tasks joint best} 个上不逊于只调整其中一侧，而在 Beers 上，训练规则选择只有在数据准备之后才带来收益。配合各数据类型自身的证据，同样的数据动作可以迁移到传感器时序数据与大语言模型的指令微调，独立验收则控制了采纳更差表的风险，重训之后同样成立。一旦基础模型在任务表上后训练，这张表的准备就应与模型调优处在同一个回路中。

\section{相关工作}
\label{app:related-matrix}

表~\ref{tab:related} 按本文的定义汇总以下各方法的动作与信息来源。仅基于标签预测计算的分数受命题~\ref{prop:interface-limit} 的召回率上界约束，
基于梯度的分数还使用模型导数。CARVEPrep 把取值修改和记录权重这两类动作与结构证据、候选评估及模型反馈结合。
下文介绍各方法的原始形式，表~\ref{tab:related} 标明所比较的组件与用途。附录~\ref{app:details} 说明实验中的适配，包括基于参照信息的选择与 Picket 式重建。

\textbf{通用清洗}依据约束与统计证据提高数据正确性。
\textsc{HoloClean} 将完整性约束与概率推断结合~\citep{rekatsinas2017holoclean}。
\textsc{Raha} 用少量标注元组从数据信号学习错误检测器~\citep{mahdavi2019raha}，
\textsc{Baran} 学习修复模型~\citep{mahdavi2020baran}。
Jellyfish 对本地语言模型进行指令微调，用于错误检测、数据插补等预处理任务~\citep{zhang2024jellyfish}。
近期综述按任务与模型使用方式整理了基于语言模型的表格数据准备方法~\citep{chen2025tabprepsurvey}。

\textbf{任务相关的清洗、选择与重加权}以下游性能指导数据决策。
\textsc{ActiveClean} 将优先修复与统计估计联系起来~\citep{krishnan2016activeclean}，
\textsc{BoostClean} 根据验证性能从检测器与修复库中选择组合~\citep{krishnan2017boostclean}。
记录选择分数包括可约留出损失~\citep{mindermann2022rholoss}、早期梯度范数~\citep{paul2021datadiet}、
面向目标分布的重要性权重~\citep{xie2023dsir}，
以及记录对验证损失影响的估计~\citep{koh2017influence,xia2024less}。
Data Shapley 估计记录对预测性能的边际贡献，Data-OOB 则复用袋外预测为记录赋值~\citep{ghorbani2019datashapley,kwon2023dataoob}。
置信学习使用样本外预测概率与类别置信阈值识别并剔除疑似标签错误~\citep{northcutt2021confident}，
元学习重加权通过干净验证损失的元梯度调整记录权重~\citep{ren2018reweight}。在指令微调中，IFD 依据指令跟随难度选择样本~\citep{li2024ifd}，
LIMA 使用少量经过精心整理的演示样本~\citep{zhou2023lima}。Rho-1 在持续预训练中依据相对参照模型的超额损失选择词元损失项，同时保留输入上下文~\citep{lin2024rho1}。
\textsc{Picket} 利用重建损失统计过滤训练记录，并通过结合输入与重建损失的类别专属检测器识别受污染的推理查询~\citep{zheng2022picket}。

\textbf{面向基础模型的数据准备}使任务数据适合预训练模型。
表格基础模型使用支持记录进行上下文预测，或在任务数据上后训练
~\citep{hollmann2025tabpfn,qu2025tabicl,ma2025tabdpt}。
针对 TabPFN-v2 的系统研究比较了全参数与参数高效微调~\citep{rubachev2025finetuning}。
该研究考察模型适配及其对上下文预测的影响，CARVEPrep 则调整任务数据。本文的表格与时序实验以 TabPFN-v2 为下游模型，Alpaca 实验使用 Qwen2.5-1.5B-Instruct。
L2C2 以先验对齐为动机，依据下游表格基础模型准确率、数据质量分数、记录保留率和相对原始数据的分布稳定性惩罚，搜索表级算子序列~\citep{bertiequille2026prior}。
LoCalPFN 为每个查询检索近邻支持记录，并利用这些局部上下文微调模型~\citep{thomas2024localpfn}。
QualiTab 研究注入数据错误对 TabPFN 表征的影响，并比较干净上下文与受污染上下文的表现~\citep{papastergios2025qualitab}。
定义~\ref{def:operator} 规定用于比较这些方法的算子类。

\textbf{数据与模型联合优化}将数据决策与模型拟合结合。上述任务相关方法中，\textsc{ActiveClean}~\citep{krishnan2016activeclean} 与 \textsc{BoostClean}~\citep{krishnan2017boostclean} 把清洗决策与模型拟合联系起来。CARVEPrep 面向同一预训练下游模型重复准备数据，并跨迭代用上下文留出损失更新记录先验（第~\ref{sec:cooptim} 节）。

\textbf{风险控制与序贯检验}为固定规则族提供有限样本保证。
Learn then Test 通过包括固定顺序检验在内的多重检验程序实现风险控制~\citep{angelopoulos2021ltt}，
风险控制预测集使用经校准的风险界~\citep{bates2021rcps}，Conformal Risk Control 则在交换性与正则条件下控制有界单调损失的期望~\citep{angelopoulos2024crc}。
投注置信序列与 e 过程给出有界观测均值的任意时刻有效界~\citep{waudbysmith2023betting,howard2021confseq}。
CARVEPrep 用投注检验在留出记录上比较固定的数据与模型对，并在另一份独立核验样本上校准修复风险。

\section{预备知识}
\label{app:prelim}

\textbf{研究对象与范围。}本节固定全文所讨论的对象。这些定义给出证据通道所作用的错误分类、其输出可由四种动作表示的算子类、描述准备后表的两个坐标、为准备方案评分的两种学习设定，以及产生经验证修复取值的见证规则。末尾的假设是附录~\ref{app:acceptance-proof} 中验收保证成立所需的采样条件。

\paragraph{定义。}
\label{app:definitions}

设 $D$ 为含 $n$ 条记录与 $d$ 列的关系表（$n,d$ 为正整数），其中 $x_{ij}$ 表示记录 $r_i$ 在列 $j$ 上的单元，$X_j$ 表示第 $j$ 列，$j_y$ 表示目标列，$\mathcal{V}(X_j)$ 表示第 $j$ 列的合法值域。函数依赖集合 $\Sigma$ 中的 $A \to B$ 要求在列 $A$ 上取值相同的记录在列 $B$ 上也取值相同。全文的决策单位是记录，证据单位是单元。

设 $\mathcal N_j$ 为指定的缺失标记集合，它与包含真实单元值的合法值域 $\mathcal V(X_j)$ 不相交。
错误观测若属于 $\mathcal N_j$，则为缺失，若同时在这两个集合之外，则为语法错误，其余为域内错误取值。
最后一种情形在 $j\ne j_y$ 时为特征语义错误，在 $j=j_y$ 时为标签噪声。
该分类构成错误单元的一个划分，取值均正确的重复记录通过其权重处理。缺失标记与格式约束提供逐单元证据。边际重抽从所在列的干净边际分布中重新抽取单元，重抽位置的选择独立于干净取值且独立于原记录。该过程在期望意义下保持列边际分布，同时造成语义错误，结构证据通过比较在 $A$ 上取值相同的记录检测这类错误（定义~\ref{def:witness}）。标签噪声需要目标列的证据。

\begin{definition}[准备算子]
\label{def:operator}
\emph{准备算子}将 $D$ 映为 $(D',\sw)$，其中 $D'$ 与 $D$ 的行列相同，$\sw\in[0,1]^n$。
每个输出行及其权重只依赖对应的输入记录、该记录的证据与表级统计量，不依赖其他记录的输出。
创建记录与大于一的权重均在该类之外。
\end{definition}

\textbf{动作表示的覆盖性。}附录~\ref{app:search-space} 证明可用取值与权重输出的规范表示，并刻画记录预算下的搜索空间。

\begin{definition}[质量状态]
\label{def:quality-state}
\emph{质量状态}是准备后的表及其权重的一对统计量 $\qstate(D_\pi, \sw) = (\psid, \psim)$。坐标 $\psid$ 是\emph{残留错误}，即准备后表中错误单元的归一化加权计数，
\begin{equation}
\psid(D_\pi, \sw) \;=\; \frac{1}{n d}\sum_{i=1}^{n} \sw_i \bigl|\{j : x^{\pi}_{ij} \neq x^{\star}_{ij}\}\bigr|,
\label{eq:kappa}
\end{equation}
其中 $x^{\star}$ 是真实取值，$x^{\pi}$ 是准备后的取值，求和遍历包含目标列在内的全部 $d$ 列。坐标 $\psim$ 是\emph{有效覆盖}，即权重的有效样本量与记录数之比，
\begin{equation}
\psim(\sw) \;=\; \frac{1}{n}\cdot\frac{\bigl(\sum_{i} \sw_i\bigr)^{2}}{\sum_{i} \sw_i^{2}},
\label{eq:eta}
\end{equation}
对非零权重向量，它是 Kish 有效样本量~\citep{kish1965survey} 与 $n$ 之比，并约定 $\psim(0)=0$。等权保留 $m$ 条记录时 $\psim=\frac{m}{n}$，在同一保留集合上不均匀的权重使其降低。\textsc{DownweightAll} 给每条可疑记录赋权重 $\sw_{\min}\in(0,1)$。当 \textsc{NoFix}、\textsc{RepairAll}、\textsc{DeleteAll} 与 \textsc{DownweightAll} 映为四个不同点时，该坐标对分离四种统一策略，这正是附录~\ref{app:state-screening} 所用的判据。
\end{definition}

\begin{definition}[设定]
\label{def:regime}
在\emph{后训练设定}中要求 $\sum_i\sw_i>0$，未被删除的训练记录上的损失为
\[
\bar\ell=\frac{\sum_i\sw_i\ell_i}{\sum_i\sw_i}.
\]
被删除的记录既不进入训练，也不进入上下文。上下文构建以 $\sw_i$ 为基础概率抽取其他记录，并补足类别覆盖。
在\emph{上下文设定}中，准备后的表只用作支持集，其中每条正权重记录出现一次，零权重记录不出现。选择阶段的 ICL 筛选则以 $\sw_i$ 为进入概率抽取支持集（附录~\ref{app:regimes}）。
\end{definition}

\begin{definition}[参照集]
\label{def:reference-frame}
\emph{参照集} $\Dref$ 是与测试集分离、供各比较方法共享的小规模干净任务样本，代表实践中可获得的经验证外部信息，即经核验的取值、标签与专家规则。
它用于先验拟合、候选构造与评估，以及早停，不进入最终下游模型的梯度训练数据。
\end{definition}

\begin{definition}[见证与证据层级]
\label{def:witness}
固定 $\Sigma$ 中的 $A \to B$ 与记录 $r_i$。其 $A$ 组是与它共享 $A$ 取值的记录集合。当该组至少含 $m_{\mathrm{grp}}$ 条记录、其中严格多数记录取同一个 $B$ 值、且 $x_{iB}$ 不是该值时，该组是 $x_{iB}$ 的\emph{有向见证}，记作 $x_{iB} \in \Wdir$。当该组含至少两个不同的 $B$ 取值但不存在严格多数时，它是\emph{无向见证}，记作 $x_{iB} \in \Wtie$。经验证的有向证据的类别编码取 $c_{ij}=2$，未解决的可疑证据取 $c_{ij}=1$，没有此类证据时取 $c_{ij}=0$。有证据单元的分数为 $\tier_{ij}=c_{ij}+0.999u_{ij}$，其中 $u_{ij}\in[0,1]$ 为对应通道的证据强度，无此类证据的单元取 $\tier_{ij}=0$。记录排序对这些分数求和。有向见证提供多数候选，仅当多数取值的支持度至少为 $r_{\min}$ 且多数差距至少为 $m_{\min}$ 时才使用该候选（附录~\ref{sec:detection_detail}）。命题~\ref{prop:interface-limit} 给出真实取值等于该多数并通过两个阈值的概率下界。无向见证表明组内存在不一致，但不给出候选取值。只含一条记录的组在该依赖上没有可比较的记录。
\end{definition}

\subsection{证据通道}
\label{sec:detection_detail}

证据收集结合依赖见证、缺失标记、格式与拼写检查，以及数值异常分数（算法~\ref{alg:detection}）。对依赖 $A\to B$，按观测到的 $A$ 值分组，统计非缺失的 $B$ 值。
令 $n_g$ 为计数总量，$c_1,c_2$ 为最高与次高频次，仅有一个取值时令 $c_2=0$。当组满足最小规模要求，且 $c_1>n_g/2$、$\frac{c_1}{n_g}\ge r_{\min}$、$\frac{c_1-c_2}{n_g}\ge m_{\min}$ 时，最高频取值成为缺失或不一致单元的修复候选。
格式、拼写与异常通道完成后，如果该记录的决定属性单元被标为可疑，则撤销其依赖候选，同时保留违反证据。
格式候选要求保持内容的规范化且符合列内主导模板，拼写候选要求在低基数列中存在编辑距离为一、频次高得多的唯一邻居，数值通道标记鲁棒离群值，在非时序表上只贡献可疑标记，在时序表上给出经局部时间平滑性检查的插值候选。


分类任务存在带标签参照集时，记录先验为
\[
\sFM_i=\frac{\operatorname{clip}\!\left(\log\frac{p(y_i)}{p(y_i\mid x_i)},0,\log C\right)}{\log C},
\qquad C=\max\{2,\text{number of reference classes}\}.
\]
概率由参照数据以观测特征估计。标签规则在 $p(y_i\mid x_i)\le\tau p(y_i)$ 时标记该记录，全文取 $\tau=1$，附录~\ref{sec:label-rule} 区分这一似然比判据与针对实际错标的 Bayes 决策。没有参照集时，以其余折为上下文给记录评分。结构证据 $\sDB_{ij}$ 记录依赖违反强度。单元带有见证层级，或其先验分数或结构证据达到固定水平时，计为可疑。命题~\ref{prop:interface-limit} 给出多数候选的正确性条件与标签条件分数的召回极限。

\begin{algorithm}[t]
\caption{证据收集}
\label{alg:detection}
\footnotesize
\begin{algorithmic}[1]
\REQUIRE 表 $D$，依赖集合 $\Sigma$，模型 $M$，可选参照集 $\Dref$，候选的最小支持度与差距要求
\ENSURE 带类型证据、候选取值与验证结果
\STATE 计算参照条件的记录与单元先验，没有参照集时使用五折分离上下文评分
\STATE 标记缺失单元，并在观测表上形成依赖组
\FOR{每个 $A\to B\in\Sigma$ 及各符合条件的组}
    \STATE 标记缺失或不一致的 $B$ 单元，以组规模、支持度与差距验证多数取值
    \STATE 验证通过时赋候选与有向层级，否则保留可疑标记
\ENDFOR
\STATE 按各自验证条件运行格式与拼写通道
\STATE 补充数值异常或时序尖峰证据
\STATE 撤回决定属性可疑的依赖违反修复候选
\STATE 对记录先验应用标签规则
\STATE 需要时计算可选的列条件先验
\RETURN 层级、候选、验证结果、$\sFM$ 与 $\sDB$
\end{algorithmic}
\end{algorithm}

\subsection{检测可用的信息}
\label{app:evidence-proof}
\begin{proposition}[预测信息与结构恢复]
\label{prop:interface-limit}
固定预测模型及其参照信息。令 $V\in\{0,1\}$ 表示实际依赖违反，$\vartheta=\Pr(V=1)\in(0,1)$，$Z$ 为检测器读取的信息。记 $Q_v=\mathcal L(Z\mid V=v)$、$\delta_Z=\mathrm{TV}(Q_1,Q_0)$。给定选择比例 $\varrho\in[0,1]$，任意满足 $\mathbb E a(Z)\le\varrho$ 的可测随机规则 $a(Z)\in[0,1]$ 均满足
\begin{equation}
 \mathrm{Recall}_{Z}(\varrho)
 \le\min\left\{1,\frac{\varrho}{\vartheta},\varrho+(1-\vartheta)\delta_Z\right\},
 \label{eq:interface-gap}
\end{equation}
其中召回率取这些规则的 $\mathbb E[a(Z)\mid V=1]$ 的上确界。存在一个在干净数据中严格成立的函数依赖 $A\to B$，对其施加边际重抽污染后，$Z=(y,P_M(\cdot\mid x))$ 即使对贝叶斯最优预测模型也满足 $Q_1=Q_0$，而仍占组内多数的真实取值能够识别每个被改变的 $B$ 单元。

更一般地，在注入错误前固定一个含 $N$ 条记录的样本池及其中含 $m\ge m_{\mathrm{grp}}$ 条记录的完整依赖组，$N\ge m$。组内干净 $B$ 值一致，样本池的决定属性在整个注入过程中保持不变，参与比较的 $B$ 值均非缺失。错误指示可以相互独立且各自概率至多为 $\rho$，也可以限于从样本池中均匀不放回抽取的 $K$ 个位置，且 $\tfrac{K}{N}\le\rho$。对附录~\ref{sec:detection_detail} 的支持度与差距阈值，令
\begin{equation}
 q_* =\min\left\{\frac12,1-r_{\min},\frac{1-m_{\min}}2\right\},
 \qquad 0<\rho<q_*.
 \label{eq:witness-tolerance}
\end{equation}
以至少
\begin{equation}
 1-\exp\{-m\,\mathrm{kl}(q_*\Vert\rho)\},\qquad
 \mathrm{kl}(u\Vert v)=u\log\frac uv+(1-u)\log\frac{1-u}{1-v},
 \label{eq:witness-recovery}
\end{equation}
的概率，真值是该组唯一的多数值，同时通过两个阈值，并且据此进行的少数值检验恰好识别全部被改变单元。
对不放回抽样，更精确的恢复概率下界为
\begin{equation}
 \sum_{\ell=0}^{\lceil mq_*\rceil-1}
 \frac{\binom K\ell\binom{N-K}{m-\ell}}{\binom Nm},
 \label{eq:witness-finite-population}
\end{equation}
其中超出取值范围的二项式系数取零。
\end{proposition}
\begin{proof}
记 $r_v=\mathbb E[a(Z)\mid V=v]$、$q=\mathbb E a(Z)$。全变差给出 $r_1-r_0\le\delta_Z$，故 $r_1=q+(1-\vartheta)(r_1-r_0)\le\varrho+(1-\vartheta)\delta_Z$。混合恒等式 $q=\vartheta r_1+(1-\vartheta)r_0$ 还给出 $r_1\le\tfrac{\varrho}{\vartheta}$。

构造两个等大的 $A=0,1$ 组，每组 $m\ge3$ 条记录，干净值满足 $B=A$，标签为独立公平二元变量。处处预测 $\tfrac{1}{2}$ 的模型是贝叶斯最优模型。每组一个 $B$ 独立于标签从二元边际重抽，再均匀抽取一条记录。此时 $\vartheta=\tfrac{1}{2m}$，而 $V$ 与标签及常数预测均独立，故 $Q_1=Q_0$。每组始终保留至少 $m-1>\tfrac{m}{2}$ 个真值，因此与多数值比较便恰好识别全部被改变单元。对仅依赖 $A$ 的标签分布及模型 $p(y\mid A)$，相同构造也成立。

为证明概率界，令 $N_e$ 为组内错误值的数量。在 $N_e<mq_*$ 时，真值占比为 $1-\tfrac{N_e}{m}>\max\{\tfrac{1}{2},r_{\min}\}$，其与任一其他值的频率差至少为 $1-\tfrac{2N_e}{m}>m_{\min}$，因此三个结论在该事件上同时成立。对相互独立的错误，由概率上界 $\rho$，当 $s>0$ 时有
\[
 \Pr(N_e\ge mq_*)\le
 e^{-smq_*}\mathbb E e^{sN_e}
 \le e^{-smq_*}(1-\rho+\rho e^s)^m.
\]
对不放回抽样，令 $L$ 为组内被抽中的位置数，则 $N_e\le L$。记 $u=e^s-1\ge0$，对 $m$ 个抽样指示展开可得
\[
 \mathbb E e^{sN_e}\le\mathbb E e^{sL}
 =\sum_{\ell=0}^m\binom m\ell u^\ell\frac{(K)_\ell}{(N)_\ell}
 \le\left(1-\frac{K}{N}+\frac{K}{N}e^s\right)^m
 \le(1-\rho+\rho e^s)^m,
\]
其中 $(a)_\ell=a(a-1)\cdots(a-\ell+1)$，$(a)_0=1$。上式使用 $\tfrac{(K)_\ell}{(N)_\ell}\le(\tfrac{K}{N})^\ell$，$\ell>K$ 时分子为零。由于 $L$ 服从超几何分布，$\Pr(L<mq_*)$ 即为式~\eqref{eq:witness-finite-population}。两种抽样方式因此具有相同的指数矩上界。
取 $s=\log\frac{q_*(1-\rho)}{\rho(1-q_*)}>0$，得到 $\exp\{-m\,\mathrm{kl}(q_*\Vert\rho)\}$，即式~\eqref{eq:witness-recovery}。
\end{proof}

\textbf{标签规则的含义。}
\label{sec:label-rule}
设 $Y^\star\sim p(\cdot\mid x)$，独立的 $C\sim\mathrm{Bernoulli}(\rho)$ 触发从类别边际重抽，给定 $x$ 后重抽取值独立于 $Y^\star$，否则 $Y=Y^\star$。对观测类别 $y$，记 $q=p(y\mid x)$、$b=p(y)>0$、$d=(1-\rho)q+\rho b>0$。条件化得到
\begin{equation}
 \Pr(C=1\mid x,Y=y)=\frac{\rho b}{d},\qquad

\subsection{加权后训练中的精确动作优势}
\label{app:capacity}
上一小节给出证据能够识别什么的界限，但没有说明一个已识别的错误对模型值多少，本小节在一个可以给出精确答案的族上回答这个问题。本文分析取值修改与记录权重如何改变线性模型拟合后能够实现的预测。设 $v_1,\ldots,v_m\in\mathbb R^m$ 线性无关。对每个 $j$，训练数据包含一条固定的单位权重锚定记录 $(\sqrt{a_j}v_j,0)$，其中 $a_j>0$，以及一条初始取值为 $(z_j^0v_j,y_j^0)$、权重为一的可干预记录。其有限可用取值配置集合 $\mathcal V_j$ 由配置 $(z,y)$ 组成，并包含原配置 $(z_j^0,y_j^0)$。修复选择另一取值配置，删除将权重设为零，降权将权重设为零与一之间。权重为零时，取值仍采用原配置表示。修复与降权的组合计为一次干预。锚定记录保持不变，至多允许 $b\in\{0,\ldots,m\}$ 条可干预记录偏离原配置。

对策略 $\pi$，归一化加权最小二乘拟合最小化
\begin{equation}
 L(\theta;\pi)=\frac{\sum_{j=1}^m a_j(\theta^\top v_j)^2+
 \sum_{j=1}^m w_j(z_j\theta^\top v_j-y_j)^2}{m+\sum_jw_j}.
 \label{eq:anchored-fit}
\end{equation}
记 $q_j=\theta^\top v_j$。以这些向量为列的矩阵可逆，因此这些预测坐标可以独立变化，唯一的拟合值为
\begin{equation}
 q_j(z,y,w)=\frac{wzy}{a_j+wz^2},\qquad
 q_j^0=\frac{z_j^0y_j^0}{a_j+(z_j^0)^2}.
 \label{eq:attainable-coefficient}
\end{equation}
设任务总体满足 $\Pr(X=v_j)=p_j>0$、$\sum_jp_j=1$、$\mathbb E[Y\mid X=v_j]=t_j$，且 $\mathbb E Y^2<\infty$。总体平方损失的超额风险为 $R(q)=\sum_jp_j(q_j-t_j)^2$。

对包含 $(z_j^0,y_j^0,1)$ 的允许取值与权重三元组 $(z,y,w)$ 集合 $\mathcal M_j$，定义其可达预测集合与最大局部风险降幅为
\begin{equation}
 \begin{aligned}
 S_j^{\mathcal M}&=\{q_j(z,y,w):(z,y,w)\in\mathcal M_j\},\\
 h_j^{\mathcal M}&=p_j\bigl[(q_j^0-t_j)^2-\operatorname{dist}(t_j,S_j^{\mathcal M})^2\bigr]\ge0.
 \end{aligned}
 \label{eq:attainable-gain}
\end{equation}
假设每个 $S_j^{\mathcal M}$ 均为紧集。令 $\operatorname{Top}_b(h)$ 表示最大的 $b$ 个分量之和，并约定 $\operatorname{Top}_0(h)=0$。

\begin{theorem}[记录预算下的精确优势]
\label{thm:budgeted-action-advantage}
对于式~\eqref{eq:anchored-fit} 中的学习器，在配置集合 $\mathcal M$ 内至多干预 $b$ 条记录时，最小超额风险为
\begin{equation}
 R_{\mathcal M}^\star(b)=R(q^0)-\operatorname{Top}_b(h^{\mathcal M}).
 \label{eq:exact-budget-risk}
\end{equation}
因此，若每条记录上的配置集合均满足嵌套关系 $\mathcal M^A_j\subseteq\mathcal M^B_j$，则
\begin{equation}
 R_A^\star(b)-R_B^\star(b)=
 \operatorname{Top}_b(h^B)-\operatorname{Top}_b(h^A)\ge0.
 \label{eq:exact-action-advantage}
\end{equation}
对每个取值配置，令 $c_j(z,y)=\tfrac{zy}{a_j+z^2}$，并记 $C_j=\{0\}\cup\{c_j(z,y):(z,y)\in\mathcal V_j\}$。四种动作限制下的可达集合分别为
\begin{equation}
 \begin{aligned}
 S_j^{\mathrm{RD}}&=\{0,q_j^0\},&
 S_j^{\mathrm{no\ repair}}&=[\min(0,q_j^0),\max(0,q_j^0)],\\
 S_j^{\mathrm{no\ fractional}}&=C_j,&
 S_j^{4}&=[\min C_j,\max C_j].
 \end{aligned}
 \label{eq:action-reachability}
\end{equation}
其中，RD 只允许保留与删除。no repair 保持原取值，允许 $[0,1]$ 内的全部权重。no fractional 允许全部可用取值配置，但权重限于 $\{0,1\}$。完整动作集合允许全部可用配置及 $[0,1]$ 内的全部权重。
\end{theorem}
\begin{proof}
式~\eqref{eq:anchored-fit} 的分母不依赖 $\theta$。在坐标 $q$ 下，分子是系数为 $a_j+w_jz_j^2>0$ 的严格凸二次式之和，因而得到式~\eqref{eq:attainable-coefficient}。每个策略至多改变 $b$ 个预测坐标，第 $j$ 个坐标的风险降幅不超过 $h_j^{\mathcal M}$，故总降幅不超过 $\operatorname{Top}_b(h^{\mathcal M})$。反之，选取降幅最大的 $b$ 个坐标，并分别取最接近 $t_j$ 的可达预测。紧性保证这些预测能够取到。降幅为零时可保留原配置，不消耗预算。该策略达到上述界，证明了式~\eqref{eq:exact-budget-risk}。两式相减即得式~\eqref{eq:exact-action-advantage}。

固定 $(z,y)$ 后，$q_j(z,y,w)$ 关于 $w$ 的导数为 $\tfrac{a_jzy}{(a_j+wz^2)^2}$。因此，当 $w$ 从零变化到一时，拟合预测覆盖零与 $c_j(z,y)$ 之间的区间。每个区间都包含零，故其并集为 $[\min C_j,\max C_j]$。其余动作限制分别给出式~\eqref{eq:action-reachability} 中的其他集合。
\end{proof}

\end{equation}

 \label{eq:eight-record-risks}

\end{proposition}
\begin{proof}

 \widehat\theta_j=\frac{w_jz_j}{1+w_jz_j^2},\qquad
 R(\widehat\theta)=\frac14\sum_{j=1}^4(\widehat\theta_j-t_j^0)^2,
 \qquad t^0=\left(\frac12,\frac12,0,\frac13\right),
 \label{eq:weighted-separation-fit}
\end{equation}
其中，$X=e_j$ 的概率均相同，且 $Y\mid X=e_j\sim\mathrm{Bernoulli}(t_j^0)$。

\begin{corollary}[扰动下的分离]
\label{cor:stable-separation}
在命题~\ref{prop:weighted-separation} 中，保持训练标签、可用配置的对应关系及记录预算不变。对每条锚定记录的特征向量、每条可干预记录的原始特征向量及可用修复向量施加欧氏范数至多为 $\zeta$ 的扰动。目标分布仍均匀取 $e_1,\ldots,e_4$，其条件均值 $t\in[0,1]^4$ 满足 $\|t-t^0\|_\infty\le\eta$。若
\[
 \zeta\le\frac1{1000},\qquad \eta\le\frac1{100},
\]
则三种受限配置集合的最优超额风险均至少比完整配置集合高 $\tfrac{1}{288}$。特征扰动方向可以任意选取。
\end{corollary}
\begin{proof}
对任意策略 $\pi$，记原实例的未归一化正规方程为 $H_\pi\theta_\pi=b_\pi$。有 $H_\pi=\operatorname{diag}(1+w_j)\succeq I$ 且 $\|\theta_\pi\|_2\le1$。扰动后，八条记录的权重均不超过一，原始特征向量的范数均为一，且只有四条可干预记录的标签非零。因此，对包括连续权重在内的全部策略，一致有
\[
 \|\widetilde H_\pi-H_\pi\|_{\mathrm{op}}\le16\zeta+8\zeta^2=:A_\zeta,
 \qquad \|\widetilde b_\pi-b_\pi\|_2\le4\zeta.
\]
由 $A_\zeta<1$，扰动后的拟合解仍唯一。将两个正规方程相减，得到
\begin{equation}
 \|\widetilde\theta_\pi-\theta_\pi\|_2
 \le\frac{4\zeta+A_\zeta}{1-A_\zeta}
 =\frac{20\zeta+8\zeta^2}{1-16\zeta-8\zeta^2}=:\kappa_\zeta.
 \label{eq:fit-perturbation}
\end{equation}
令 $e=\tfrac{\kappa_\zeta}{2}+\eta$。在所给扰动半径下，$e\le\tfrac{248049}{12299900}<\tfrac{1}{48}$，小于每种受限配置集合的 $\sqrt r$。原完整配置集合的最优策略在扰动后的风险至多为 $e^2$。对于原最小风险为 $r$ 的受限配置集合，每个扰动后预测与新目标的距离均至少为 $\sqrt r-e$，其中距离按范数 $\tfrac{1}{2}\|\cdot\|_2$ 衡量。因此，
\begin{equation}
 \widetilde R_{\mathrm{restricted}}^\star-\widetilde R_4^\star
 \ge r-2\sqrt r\,e.
 \label{eq:stable-action-gap}
\end{equation}
函数 $r-2\sqrt r\,e$ 在 $r\ge\tfrac{1}{144}$ 时递增。式~\eqref{eq:eight-record-risks} 中每种受限配置集合的 $r$ 均不小于 $\tfrac{1}{144}$，故右侧至少为 $\tfrac{1}{144}-2\cdot\tfrac{1}{12}\cdot\tfrac{1}{48}=\tfrac{1}{288}$。
\end{proof}

\subsubsection{记录动作的交互}
\label{sec:action-interaction}

\begin{equation}
 I(\sigma,\tau)=\Delta(\sigma\tau)-\Delta(\sigma)-\Delta(\tau).
 \label{eq:action-interaction}
\end{equation}

\begin{proposition}[记录动作存在交互]
\label{prop:action-interaction}

\begin{equation}
 q=\frac{\sum_iw_iz_iy_i}{1+\sum_iw_iz_i^2}.
 \label{eq:shared-direction-fit}
\end{equation}
原表给出 $q^0=\tfrac{3}{7}$。删除三条错标记录，即改动 $\sigma$，给出 $q=0$。修复第六条记录，即改动 $\tau$，给出 $q=\tfrac{5}{7}$，两组改动同时施加给出 $q=\tfrac{1}{2}$。超额风险 $(q-\tfrac{1}{2})^2$ 依次为 $\tfrac{1}{196}$、$\tfrac{1}{4}$、$\tfrac{9}{196}$ 与 $0$，故 $\Delta(\sigma)=-\tfrac{12}{49}$，$\Delta(\tau)=-\tfrac{2}{49}$，$\Delta(\sigma\tau)=\tfrac{1}{196}$。
\end{proof}

\begin{proposition}[固定评分函数的验收]
\label{prop:acceptance}
给定验收前固定的全部信息，包括开发信息及可选的校准信息，固定 $K_c\ge1$ 个候选评分函数 $g_1,\ldots,g_{K_c}$ 与参照评分函数 $g_0$，其取值均在 $[0,1]$ 内。候选数 $K_c$ 和全部已拟合模型在访问独立验收序列 $X_1,X_2,\ldots$ 之前固定，该序列独立于全部固定信息，由任务总体的独立同分布记录构成（假设~\ref{as:ref-iid}）。令 $d_{k,t}=g_k(X_t)-g_0(X_t)$，$\mu_k=\mathbb E[d_{k,t}]$。对于 $0\le\epsilon<1$ 与 $\delta_2\in(0,1)$，定义
\begin{equation}
 E_{k,0}=1,\qquad
 E_{k,t}=\prod_{s=1}^t\{1+\nu_{k,s}(d_{k,s}+\epsilon)\},
 \qquad 0\le\nu_{k,s}\le\frac{1}{2(1-\epsilon)}.
 \label{eq:acceptance-process}
\end{equation}
每个投注量 $\nu_{k,s}$ 可以使用验收前固定的信息及全部候选在记录 $1,\ldots,s-1$ 上的评分，但不能使用第 $s$ 条或之后的记录。仅在候选的过程达到 $\tfrac{K_c}{\delta_2}$ 后允许采纳，没有候选符合条件时保留参照方案。则
\begin{equation}
 \Pr\!\left(\exists k,t:\ \mu_k< -\epsilon,\ E_{k,t}\ge\frac{K_c}{\delta_2}\right)\le\delta_2.
 \label{eq:acceptance-control}
\end{equation}
因此，除去概率至多为 $\delta_2$ 的事件，从符合条件的候选中作出的任何选择，其总体分数均不低于固定参照分数减去 $\epsilon$，包括在依赖数据的停时作出选择。没有候选时保留参照方案。
\end{proposition}
\begin{proof}
给定验收前固定的信息，令 $\mathcal F_{t-1}$ 为这些信息与记录 $X_1,\ldots,X_{t-1}$ 生成的 $\sigma$-代数。对于 $\mu_k\le-\epsilon$ 的候选，独立性与可预测性给出
\[
 \mathbb E[1+\nu_{k,t}(d_{k,t}+\epsilon)\mid\mathcal F_{t-1}]
 =1+\nu_{k,t}(\mu_k+\epsilon)\le1.
\]
由 $d_{k,t}+\epsilon\ge-(1-\epsilon)$，式~\eqref{eq:acceptance-process} 中每个因子均不小于 $\tfrac{1}{2}$，且不大于 $1+\tfrac{1+\epsilon}{2(1-\epsilon)}$。因此，$E_{k,t}$ 是初值为一的非负超鞅。Ville 不等式将其越界概率界为 $\delta_2/K_c$。对固定候选取联合界，再去掉条件，即得式~\eqref{eq:acceptance-control}。不同候选的过程可以共用验收记录。
\end{proof}

 D_J(x)&=\frac1R\sum_{r=1}^R\mathbf1\{f'_J(x)\ne f_{J,r}(x)\},
 &\widehat q&=\frac1m\sum_{i=1}^m D_J(U_i),\\
 q_U&=\sup\!\left\{q\in[\widehat q,1]:
 m\,\mathrm{kl}(\widehat q\Vert q)\le\log\frac{1}{\delta_3}\right\}.
 \end{aligned}
 \label{eq:final-fit-disagreement}
\end{equation}
其中 $\mathrm{kl}$ 为式~\eqref{eq:witness-recovery} 中的二元相对熵，在零和一处取通常的极限值。特别地，$\widehat q=1$ 时 $q_U=1$。
记 $P(g)=\mathbb E_{(X,Y)\sim P}g(X,Y)$，并以 $\operatorname{Acc}_P(f'_J)=\Pr_{(X,Y)\sim P}(f'_J(X)=Y)$ 表示本次训练所得最终分类器的总体准确率，则
\begin{equation}
 \Pr\!\left(A\cap\left\{
 \operatorname{Acc}_P(f'_J)<P(g_0)-\epsilon-q_U
 \right\}\right)\le\delta_2+\delta_3.
 \label{eq:final-fit-transfer}
\end{equation}
\end{corollary}
\begin{proof}
给定使 $A$ 成立的完整选择与训练历史 $\mathcal H$，函数 $D_J$ 和 $f'_J$ 均固定。记 $q=\mathbb E_{P_X}D_J(X)$。对于 $\lambda<0$，由 $[0,1]$ 上的凸性可得 $\mathbb E[e^{\lambda D_J(U_i)}\mid\mathcal H]\le1-q+qe^\lambda$。应用指数形式的 Markov 不等式，并对 $\lambda$ 优化，得到
\[
 \Pr(\widehat q\le x\mid\mathcal H)\le
 \exp\{-m\,\mathrm{kl}(x\Vert q)\},\qquad 0\le x<q.
\]
反演该界得到 $\Pr(q>q_U\mid\mathcal H)\le\delta_3$。$q=0$ 与 $q=1$ 的情形直接成立。对每个 $(x,y)$，
\[
 \mathbf1\{f'_J(x)=y\}\ge g_J(x,y)-D_J(x).
\]
取期望得 $\operatorname{Acc}_P(f'_J)\ge P(g_J)-q$。命题~\ref{prop:acceptance} 将采纳满足 $P(g_J)<P(g_0)-\epsilon$ 的候选的概率控制在 $\delta_2$ 以内。去掉条件并取联合界，即得式~\eqref{eq:final-fit-transfer}。
\end{proof}

该上界 $q_U$ 可通过一维单调搜索计算。由 $q\ge x$ 时 $\mathrm{kl}(x\Vert q)\ge2(q-x)^2$，有 $q_U\le\min\bigl\{1,\widehat q+\sqrt{\tfrac{1}{2m}\log\tfrac{1}{\delta_3}}\bigr\}$。当最终分类器与每个评估分类器在全部抽样特征上的预测均一致时，$\widehat q=0$，且 $q_U=1-\delta_3^{\frac{1}{m}}$，新增损失上界按 $\tfrac{1}{m}\log\tfrac{1}{\delta_3}$ 的阶衰减。

\subsubsection{替换规则的校准}
对独立核验的单元真值使用固定顺序检验~\citep{angelopoulos2021ltt} 可以控制修复错误。引理明确了单条记录包含多个修改单元时的采样单位。

\begin{lemma}[基于独立记录的修复风险校准]
\label{lem:risk-control-gate}
在抽样前固定 $L\ge1$ 个完整替换规则、规则顺序及全部分配上下文，
再从部署总体中抽取固定数量的 $h\ge1$ 条独立同分布核验记录
$Z_1,\ldots,Z_h$，且样本与上述固定信息独立。
每条记录包含 $d\ge1$ 个单元，每个规则仅使用该记录及固定上下文执行修改。
令 $M_j(Z)$ 为规则 $j$ 实际改变取值的单元数，
$C_j(Z)$ 为其中修改后取值与真值不符的单元数。
真值仅用于核验修改，不参与修改选择。定义
\[
 A_j=\frac{M_j}{d},\qquad B_j=\frac{C_j}{d},\qquad
 R_j^{\mathrm{cell}}=
 \frac{\mathbb E B_j}{\mathbb E A_j},
\]
并在 $\mathbb E A_j=0$ 时令 $R_j^{\mathrm{cell}}=0$。
固定 $\alpha,\delta\in(0,1)$，令
$\widehat A_j=h^{-1}\sum_{t=1}^h A_j(Z_t)$，
并类似定义 $\widehat B_j$。按预定顺序检验规则，当
\begin{equation}
 \widehat B_j-\alpha\widehat A_j+
 \sqrt{\frac{1}{2h}\log\frac{1}{\delta}}\le0,
 \label{eq:record-repair-test}
\end{equation}
时继续，在首次检验失败时停止。
记 $\mathcal J_{\mathrm{pass}}$ 为停止前通过检验的规则集合，则
\[
 \Pr\!\left(\exists j\in\mathcal J_{\mathrm{pass}}:
 R_j^{\mathrm{cell}}>\alpha\right)\le\delta.
\]
可以返回任一通过检验的规则，若没有规则通过，则不作修改。满足 $M_j\equiv0$ 的规则有 $R_j^{\mathrm{cell}}=0$，可直接准入，固定顺序检验按原有次序遍历其余规则。
\end{lemma}
\begin{proof}
条件于固定规则和上下文。由 $0\le B_j\le A_j\le1$，
变量 $W_{j,t}=B_j(Z_t)-\alpha A_j(Z_t)$ 在记录之间独立，
且落在宽度为一的区间 $[-\alpha,1-\alpha]$ 内。
对任一满足 $R_j^{\mathrm{cell}}>\alpha$ 的规则，有
\[
 \mu_j=\mathbb E W_{j,t}
 =\mathbb E A_j\,(R_j^{\mathrm{cell}}-\alpha)>0.
\]
记 $c_h=\sqrt{\tfrac{1}{2h}\log\tfrac{1}{\delta}}$，由 Hoeffding 不等式
\citep{hoeffding1963inequalities}，
\[
 \Pr(\widehat B_j-\alpha\widehat A_j+c_h\le0)
 \le \Pr\!\left(h^{-1}\sum_t W_{j,t}-\mu_j\le-c_h\right)
 \le e^{-2hc_h^2}=\delta.
\]
若有风险超标的规则通过，则预定顺序中第一个满足
$R_j^{\mathrm{cell}}>\alpha$ 的规则必然通过。
将上述界用于这个固定的首个超标规则，即得结论。
对固定信息取全概率后，该概率界仍然成立。
最后，独立于一条新记录，从 $\{1,\ldots,d\}$ 中均匀抽取一列。
该单元被修改和被错误修改的概率分别为 $\mathbb E A_j$ 与
$\mathbb E B_j$，因此 $R_j^{\mathrm{cell}}$ 恰为实际修改条件下的错误概率。
\end{proof}

若在校准前固定至多 $K_{\mathrm{cal}}\ge1$ 个替换规则族，对每个规则族以 $\tfrac{\delta_1}{K_{\mathrm{cal}}}$ 的水平应用引理~\ref{lem:risk-control-gate}，包括最终被拒绝的规则族。后续验收只考虑通过规则或不修改取值的规则。在校准样本独立于开发和验收样本的条件下，与命题~\ref{prop:acceptance} 取联合界，即以至少 $1-\delta_1-\delta_2$ 的概率同时保证修复风险不超过 $\alpha$、固定评分函数的分数损失不超过 $\epsilon$。从核验样本重新计算排序、配额或依赖组多数值的规则不满足引理条件。

\subsection{动作覆盖与搜索空间结构}
\label{app:search-space}

\textbf{取值与参与程度共同确定准备方案。}
先独立于候选值的获取方式刻画四类动作原语，再确定固定候选菜单能够表达的输出。这里，当两个输出的权重相同，且每条正权重记录的取值相同时，称它们等价。零权重记录的取值不影响定义~\ref{def:regime} 中的损失或上下文。

\begin{proposition}[准备输出的规范表示]
\label{prop:action-coverage}
定义~\ref{def:operator} 的每个输出 $(D',\sw)$ 在上述等价关系下，都能由保留、删除、修复、降权，或修复与降权的组合唯一表示。给定 $S$ 和配置互不相同的菜单 $\mathcal Z_i$，该输出能由定义~\ref{def:policy} 的策略表示，当且仅当 $S$ 外的记录保持原值与单位权重，且 $S$ 内每条正权重记录的输出配置属于 $\mathcal Z_i$。
\end{proposition}
\begin{proof}
对零权重记录，将其存储值替换为原值，得到规范的删除表示。正权重记录包含两个独立选择，即取值是否改变，以及权重是否为一。取值不变且权重为一对应保留，取值改变且权重为一对应修复，取值不变且权重在 $(0,1)$ 内对应降权，取值改变且权重在 $(0,1)$ 内对应两者组合。这些情形互斥且穷尽，确定了最终取值和权重，因此给出唯一规范表示。根据定义~\ref{def:policy}，配置属于菜单以及保留 $S$ 外记录是必要条件。它们也是充分条件，因为每个正权重输出均有唯一配置下标，而零权重输出统一取下标零。
\end{proof}

因此，插补和标签纠正选择修复值，选择或有界重要性加权选择参与程度，如例~\ref{ex:alternatives} 所示。外部修复值加入相应菜单后，便进入策略空间。这区分了\emph{动作原语的覆盖}与\emph{可用候选的覆盖}。

\textbf{记录预算关联各记录的局部选择。}
令 $\Pi_b$ 包含干预数不超过 $b$ 且总权重为正的规范策略，此时尚未施加修复错误约束。对每条记录，每个取值配置提供一个权重区间，各区间的零端点合并为删除。整体空间是这些局部选择的乘积，并限制至多 $b$ 条记录偏离保留状态。

\begin{proposition}[预算分层与可行撤回路径]
\label{prop:budget-space}
这些空间逐层嵌套，$\Pi_0\subseteq\Pi_1\subseteq\cdots\subseteq\Pi_K$，其中 $\Pi_0$ 仅含原表。若记录 $i$ 有 $m_i=|\mathcal Z_i|$ 个配置，以及包含 $0$ 和 $1$ 的有限权重网格 $\mathcal W_i\subseteq[0,1]$，记 $q_i=m_i(|\mathcal W_i|-1)$，则
\begin{equation}
 |\Pi_b|=\sum_{j=0}^{b}[t^j]\prod_{i\in S}(1+q_i t)
 -\mathbf 1\{K=n=b\},
 \label{eq:budget-space-count}
\end{equation}
其中 $[t^j]$ 提取多项式系数。进一步施加 $\mathrm{RepairError}\le\alpha$ 后，将仅在一条记录上不同的两个可行策略连接。每个策略到原表的图距离恰为 $|\mathcal I(\pi)|\le b$，因此该图连通且直径不超过 $2b$。
\end{proposition}
\begin{proof}
扩大干预上限会保留已有全部策略。每条记录有一种删除结果和 $m_i(|\mathcal W_i|-1)$ 种正权重结果，后者中有一种是保留。因此恰有 $q_i$ 种干预选择。选择 $j$ 条被干预记录，对应乘积中 $t^j$ 的系数。全部删除是唯一总权重为零的结果，且仅当 $S$ 为整张表且 $b=n$ 时被计入。

对于路径结论，撤回一次干预是将该记录恢复为原值和单位权重。这会减少预算用量，且不会降低总权重。对每条被修复记录 $i$，令 $u_i>0$ 为被改变单元数，$v_i$ 为这些改变中取值错误的个数。若还有修复，其总体错误率为 $R=\sum_i v_i/\sum_i u_i$。选择 $v_i/u_i$ 最大的记录并撤回，该比值至少为 $R$。移除一个比值不小于总体比值的分量不会提高总体比值，空和的错误率约定为零。重复该过程即可在保持 $\mathrm{RepairError}\le\alpha$ 的前提下撤回全部修复。剩余删除与降权可以按任意顺序撤回，因为两者均不改变修复错误率。每一步撤回一条被干预记录，而任何到达原表的路径都必须改变这 $|\mathcal I(\pi)|$ 条记录，因此图距离恰为 $|\mathcal I(\pi)|\le b$。将经过原表的两条路径连接，得到直径上界。
\end{proof}

当所有 $q_i=q$ 时，式~\eqref{eq:budget-space-count} 化为 $\sum_{j=0}^{b}\binom Kj q^j$，再减去可能存在的全部删除结果。一个修复候选与一个中间权重产生五种局部结果，其中包括组合动作，此时 $q=4$。修复错误约束下的撤回次序具有实质作用，因为先撤回准确修复可能提高剩余改变的错误比例。

\textbf{预算也限制质量坐标。}
令 $e_i$ 为原记录 $i$ 中的错误单元数，$T_b$ 为 $i\in S$ 中最大的 $b$ 个 $e_i$ 之和，并约定 $T_0=0$。记原始残余错误为 $\kappa_0=(nd)^{-1}\sum_i e_i$。

\begin{proposition}[质量平面中的预算包络]
\label{prop:coverage-envelope}
每个 $\Pi_b$ 中的策略均满足
\begin{equation}
 \kappa_0-\frac{T_b}{nd}\le\psid(D_\pi,\sw)\le\psim(\sw),
 \qquad \frac{\max\{n-b,1\}}{n}\le\psim(\sw)\le1.
 \label{eq:quality-budget-envelope}
\end{equation}
当 $b<n$ 时，删除 $e_i$ 最大的 $b$ 条可干预记录同时达到两个下界，且修复错误为零。当 $b=n$ 时，保留一条记录并删除其余记录也能达到有效覆盖的下界。
\end{proposition}
\begin{proof}
干预记录 $i$ 最多移除其原始残余错误贡献 $e_i/(nd)$，因此至多 $b$ 次干预最多移除 $T_b/(nd)$。记 $s=\sum_iw_i>0$、$v=\sum_iw_i^2>0$。由 $w_i\in[0,1]$ 可知 $v\le s$，因此 $\psim=s^2/(nv)\ge s/n\ge(n-b)/n$。另外，$v\le s^2$ 给出 $\psim\ge1/n$，Cauchy--Schwarz 不等式给出 $\psim\le1$。每条记录至多有 $d$ 个错误单元，因此 $\psid\le s/n\le\psim$。删除所述记录即证明下界可达。
\end{proof}

这些界刻画记录预算如何限制残余错误与有效覆盖的联合变化。策略还保留了被干预记录的身份与取值，而这些信息同样决定下游训练。因此，下游评估使用准备方案完整的取值与权重。

主要公式逐项解释，先分清它在计算什么

① 标签先验与“实际错标”不是同一概率
sᵢ = clip(log[bᵢ/qᵢ], 0, log C) / log C
qᵢ = p(yᵢ|xᵢ)，bᵢ = p(yᵢ)，C ≥ 2

q高于边缘概率b时，log比值≤0，先验被截为0；q很低时先验接近1。它是归一化不可信分数，不是错误概率。部署标签否定条件为q≤b，等号也会标记。

d = (1−ρ)q + ρb
P(触发重抽 | x,Y=y) = ρb/d
P(实际错标 | x,Y=y) = ρb(1−q)/d

重抽可能恰好重新得到真实标签，因此第二式多一个(1−q)。成本对称时，严格Bayes删除条件为(1−ρ＋2ρb)q≤ρb。论文没有把默认q≤b等同这个知道ρ的最优规则；源码某些旧注释需结合这一最新附录理解。

② 预算约束、修复风险与总成本
I(π) = {i : zᵢ ≠ 原配置 或 wᵢ ≠ 1}
|I(π)| ≤ min(K, ceil(fn))，RepairError(π) ≤ α，Σwᵢ > 0

K为允许干预的记录数，n是工作表行数。一个行同时修复和降权只计一次。公式是问题定义，部署算法只能用可用证据近似控制修复风险；它没有访问真值检查每个候选是否满足α。完整外部／对比候选还可能超过自身分配预算。

Σᵣ costᵣ + costfinal(r*) ≤ B

B是时间／计算总预算，包含证据、候选评分、训练、反馈和最后重训，不能只数改过多少单元格。

③ 质量坐标与它们的不足
κ = [Σᵢ wᵢ × 该行仍错误的单元数] / (n d)
η = (Σᵢwᵢ)² / [n Σᵢwᵢ²]

κ需要真值，η只需要权重。κ分母固定为原表nd，所以删除错误行能降低κ而没有修好任何值。等权保留m行时η=m/n。把所有正权重同时乘相同常数不改变η，所以η反映相对权重有效样本量，不是绝对训练质量或类别覆盖的完整量。

相同κ、η的不同表仍可能在保留身份、标签关系、训练规则上不同，不能由平面坐标直接推出准确率。

④ 排序和动作价值的两个不同任务
Tᵢ = Σⱼ tierᵢⱼ，c=2d+1
T̃ᵢ = 标签否定 ? (2c+c sᵢ) : Tᵢ
rankᵢ = N(10T̃ + N(s))ᵢ

N是表内min-max，常数向量映为0。rank只决定谁先获得预算，也控制降权曲线。17维state中的tier_max和tier_sum是回归输入，动作价值V才决定采取哪类动作。它们不能互相替代。

当前附录明确写了求和排名及同分顺序，正文state定义中的最大层级与实现求和是不同用途，不应解读成未同步的算法矛盾。

⑤ 检测可见信息限制与多数恢复界
RecallZ(ϱ) ≤ min{1, ϱ/ϑ, ϱ+(1−ϑ)δZ}
q* = min{1/2, 1−rmin, (1−mmin)/2}
P(组真值多数且过门槛) ≥ 1 − exp[−m kl(q*‖ρ)]，0<ρ<q*

ϱ是检测器最多选取比例，ϑ是实际违反比例，δZ是错误与非错误两类输入信息分布的总变差。若预测信息与错误独立，δZ=0，召回不超过选择比例。结构读取了额外信息，因而可以突破仅预测接口的界。

多数界要求依赖干净时严格成立、决定属性不被污染、参与比较值非缺失、完整组事先固定。默认门槛下q*=0.4，而ρ=0.4不满足严格ρ<q*；不能用这一正指数界直接认证主混合实验全部组。固定不放回位置时，论文另给超几何尾概率，不应把两种采样混同。

⑥ 有限策略空间为什么会大
qᵢ = mᵢ (|Wᵢ|−1)
|Πb| = Σⱼ₌₀ᵇ [tʲ] Πᵢ∈S(1+qᵢt) − 1{K=n=b}

mᵢ是含原值在内的可用配置数，Wᵢ含0和1。删除时不同取值等价，只计一种；减掉全部删除保证Σw>0。若每行有原值、一个修复值，权重取0、0.5、1，则每行有5种不同结果，其中4种为干预，q=4。预算3、K=8时共有1＋8×4＋28×16＋56×64=4065种策略，尚未施加修复风险约束。

严格分离、微扰与质量包络分别证明什么

预算3时完整集合风险0；只保留与删除为5/72；禁止修复为1/16；禁止分数权重为1/144。第四条记录自身观测正确，降到w=1/2才把其预测从1/2移到目标1/3，所以“正确记录永远不该降权”也不是一般规律。

特征每行欧氏扰动≤0.001、目标均值无穷范数扰动≤0.01并保持标签、配置对应和预算时，论文给受限菜单与完整菜单至少1/288的差距。其证明依靠正规矩阵扰动界，不是对任意大扰动或任意神经模型的保证。

κ₀−Tb/(nd) ≤ κ ≤ η；max(n−b,1)/n ≤ η ≤ 1

Tb是可干预记录中最大的b个原始错误单元数之和。这个界限制质量坐标可达范围；它不告诉你哪张表的后训练准确率最高。
