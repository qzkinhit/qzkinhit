从可疑位置到训练信号

检测器回答“哪里可能错”，还没有决定怎么处理

① 缺失

识别 NaN。例：ibu = empty 经预处理变成 NaN。检测输出位置及均值估计，不代表已获得真正 IBU。

② 语法

RAHA 在原始字符串上检测，再加 REGEX 与 DOMAIN。例：ounces = 16.0 oz 不符合纯数值形式；本地规则限定 ABV 在 [0.001, 0.128]。

③ 语义

FD 多数投票、CFD 条件规则、DC 跨列约束。值本身合法，但与上下文矛盾，例如同一 brewery_id 对应了不一致城市。

④ 标签噪声

标签条目可由 NaN、RAHA、DOMAIN、CFD、DC 产生，并在最后过滤特征受损行；代码单列为 type=3、col=-1。论文理论中它可归于语义错误，代码为了决策另行编码。

检测结果转成错误列表 {idx, col, type, repair_value, …}。训练注入错误的 repair_value 是注入前伪真值；真实推理时可只有估值或待获取真值，不能把这些名字相同的字段当成同等可靠的答案。检测入口和实际返回结构

伪真值基准怎样选出来

DeleteFix 候选

删掉被检出错误的行，得到更少的训练样本。检错漏检意味着剩余表仍可能含错。

VE-Fill 候选

保留样本，用规则、文本相似度和近邻估值处理错误。估值可能错，但样本量更充足。

adjusted_score = CV_score × √(保留行数 / 原始行数)

每个候选做 5 折交叉验证，乘保留率平方根后取较大者。示例计算：删行候选 CV=0.90、保留 1/4，得 0.45；VE 候选 CV=0.65、全保留，得 0.65，于是选 VE。这个数值例子用于说明公式，不是 beers 实测。对应实现

“自监督”指注入前的值可自动记录，产生训练目标；它不保证 D_base 的每个值是真实世界真值。RAHA 可能另需行标注；源码还可将 RAHA 已标注行中的检出错误预先用 clean 值修复，必须独立核算。

教学指标的定义

A = 1 − 剩余错误格 / 原始 12 个特征格，删除行内错误也不再计入。V = 行保留率 × 两列方差比的均值，忽略 NaN，分母取初始脏表；V 可以大于 1。我们只在这张已知参考小表上精确计算 A。

不能从这些数字推出什么

A 高不等于模型准确率高；V 高不等于信息一定更有效。页面不编造每一步的真实下游准确率。完整实验需要把清洗后的表重新用于模型训练，再用独立验证集衡量。

DQN 看见什么

代码输入的是 10 维摘要，不是整张表

每处理一个错误，ClassificationStateExtractor.extract() 先产生 8 维，再由环境拼接剩余预算与错误比例。每个 state 是 float32 的形状 (10,)；进入网络前变为 (1,10)。

维度实际量含义与读码注意点
s0min(error_type / 3, 1)missing=0、semantic=1、syntactic=2、label=3。
s1feature_importance来自当前代理模型。标签错误固定 1；无可用值时用 0.5。
s2distance_to_boundary来自 decision_function 或预测概率，裁剪到 [0,1]；越接近边界，奖励里的 urgency=1−s2 越高。
s3idx/(n−1)归一化行位置。它仍依赖行次序，所以“数据集无关”不等于对所有重排严格不变。
s4col/(d−1)归一化列位置。标签列 col=-1 特判为 1。
s5该列检出错误数 / 全部检出错误数这是错误在列间的占比，不是该列错误数除以行数。标签错误状态采用 0.5。
s6保留行数 / 原始行数删行后下降，环境中保留物理矩阵形状并通过 deleted_rows 判断。
s7clip(当前该列方差 / 初始方差, 0, 1.5)可超过 1；不能照搬“全部状态在 [0,1]”的描述。标签错误设为 1。
s8remaining_budget / max(B,1)预算为 0 时得到 0。GT 修复使用后下降。
s9remaining_errors / max(K,1)队列剩余处理比例。已删行的其他错误也会被跳过。

从一次决定到可学习的策略

两阶段 Dueling Double DQN

第一层，3 个选择

0 保留；1 删行；2 进入第二层。输出 Q1 的形状是 (batch,3)。

第二层，2 个选择

仅当第一层选 2 时运行。0 VE 替换；1 GT 修复。输出 Q2 的形状是 (batch,2)。

state (10) → Linear(10,128) → ReLU → Linear(128,128) → ReLU
共享表示 → V(s) (1) + A(s,·) (3 或 2) → Q(s,a)=V(s)+A(s,a)−mean(A)

Dueling 把“此状态总体是否有价值”与“各动作相对优劣”分开学习。减去平均优势用于使分解可辨认。Double DQN 则让在线网络负责选下一步动作，让目标网络负责给这个动作估值，减少同一估计同时挑选和打分引入的过高估值倾向。

a* = argmaxₐ Q_online(s′, a)
y = r + (1−done) × γ × Q_target(s′, a*)
loss = mean((Q_online(s,a) − y)²)
θ_target ← τ θ_online + (1−τ) θ_target

代码 γ 默认 0.95、τ 默认 0.1；每阶段有自己的经验池与网络。训练中 ε-greedy 在随机探索和选最大 Q 之间切换，推理则纯利用。训练循环每个 episode 结束后抽取 mini-batch 回放，目标网络按配置周期更新，按分数选最佳权重，同分优先低 GT 使用。调用链 · TD 目标计算

“两阶段动作选择”与“先计划后回填”是两个概念。agent.act(state) 两次调用都使用同一个 state，中途没有先把 VE 写入数据再重新编码；最终组合成一个动作后，环境才真正更新表。查看完整映射

priority = [(1−s2)+s1+s5]/3。越靠近边界、特征越重要、该列错误占比越高，越倾向优先修复。

终局

论文的概念层

真实性、多样性与组合搜索分别解决什么问题

真实性 A

A = 1 − |E| / (n × d)

v0818 主文固定使用原表单元格数作分母。A_det 用检测标记；A_true 用真实错误。VE 消除一个标记，并不必然消除真实错误。删行会移除错误，也会减少证据。

多样性 V

V = mean_c[(n_keep/n) × (var_result,c / var_dirty,c)]

将样本保留与列内散布保留相乘。删掉靠均值的点反而可能提高剩余方差，所以 V 可以超过 1；这个统计量并不覆盖所有类别覆盖、相关性或因果结构。

目标不是直接最大化 A 或 V

π* = argmaxπ Perf(M; Dπ)
subject to Σᵢ cost(π(eᵢ)) ≤ B

对 K 个检出错误，朴素组合有 4^K 种。每个策略都可能生成一张不同训练表，训练后的模型又以非线性方式响应它。二维 (A,V) 提供分析与可视化坐标，DQN 用丰富状态做近似决策，并未枚举全空间。

理论结论的适用条件

主文讨论 NP 完全性的判定版本，包含一般逐格成本与多项式训练/评测假设；稠密可达性需要单格影响有界等条件；二维规划误差界还取决于相近 (A,V) 下性能离散度是否小。

不能由这些结论推出有限大小的任意数据集都必然呈三角形、二维统计量总是充分、或训练出的 DQN 已达到全局最优。

神经网络与TD目标手算
Dueling负责分解，Double负责分开选动作和估值
Dueling 把一个状态的总体价值V与各动作相对优势A拆成两个输出头，再合成Q；Double DQN 使用online选择下一动作，使用target给这个被选动作打分。这是两个可独立配置的设计，不是同一个术语的两种译法。
第一层与第二层使用相同输入状态
Q2的V固定0.4。此处手动给出网络头输出，输入值改变时实时重算平均优势和动作。两个V流是不同网络参数，不把Q1和Q2的数值直接混排为5个平行动作。
为什么不能直接取 target 网络最大值
默认例子中，online选择索引1，target在索引1给分5，尽管target的最大值9在索引2。Double DQN目标是0.2+0.95×5=4.95，而不是8.75。done=True时y=r，完全切断下一状态项。源码gather所在位置
从一次TD误差到网络更新，哪些张量真的有梯度
current_q=model(states).gather(...) 保留计算图；next_actions、next_q、target_q 在 torch.no_grad() 中计算，不从目标回传梯度。MSE对当前被选动作的Q产生梯度，再穿过共享MLP与Dueling分解影响网络参数。Adam更新online网络；target网络由稍后的软更新单独改变。
batch中每条记录都有自己的reward、done、下一状态动作索引。真正loss是batch内平方误差均值；单条数值只是便于手算。two_stage有两个独立buffer，只有进入第二层的记录写入第二个buffer。

复杂度与零预算
一般成本约束的判定形式被论文论证为NP完全，前提包括模型训练评估为多项式时间。B=0时只能选no-op/delete/VE，名义空间变为3^K。三种全局单一策略的最优者只是零预算最优值的下界。
有限episode、有限经验池和函数近似都不提供全局最优证书。论文消融主要检查RL内部组件，不能据此单独证明RL一定优于所有非RL预算排序方法。

 503  \subsubsection{Two-Stage Dueling Double DQN Architecture}
 504  \label{sec:dqn}
 505
 506  \cut{The Sequential MDP Loop in Figure~\ref{fig:framework} illustrates the per-error decision cycle; Example~2 walks through a concrete decision on a semantic error.}
 507
 508  \textbf{State representation.}
 509  Each error cell is encoded as a 10-D state $\mathbf{s} \in [0,1]^{10}$ in three groups (State panel, Figure~\ref{fig:framework}): \emph{local features} $s_0$--$s_5$ (type, feature importance, boundary distance, row/col indices, column error rate); \emph{global quality} $s_6$--$s_7$ ($R_{\mathit{sam}}$, $R_{\mathit{var}}$; Definition~\ref{def:diversity}); \emph{budget awareness} $s_8$--$s_9$ (remaining GT ratio, remaining-error ratio), enabling global allocation rules.
 510
 511  \textbf{Two-stage hierarchical decision.}
 512  A flat 4-action space suffers from \emph{action dominance}: GT-repair's deterministic superiority biases the agent toward repair-all. \cut{We decouple cost-free triage from cost-sensitive GT-repair. }\emph{Stage-1 (triage)} selects among three zero-cost macro-actions: no-op, delete, or enter Stage-2. \emph{Stage-2 (quality)}, triggered only when Stage-1 enters, chooses VE-replace (cost 0) or GT-repair (cost 1).\cut{ Example~2 in Figure~\ref{fig:framework} shows the same semantic error receiving GT-repair under ample budget ($s_8{=}0.8$) but VE-replace under tight budget ($s_8{=}0.1$), so the network preserves scarce GT for high-impact errors.}\cut{ Both stages use independent Dueling Double DQN networks and replay buffers.}
 513
 514  \textbf{Reward design.}
 515  A three-layer reward avoids per-step model retraining. \emph{(i) Shaping rewards}~\cite{ng1999reward} act per step by averaging boundary proximity ($s_2$), feature importance ($s_1$), and column error rate ($s_5$); GT-repair is gated by budget slack, delete is penalized, and the shaping weight decays from full to 0.1. \emph{(ii) Evaluation-step rewards}, every $N$ steps, retrain a lightweight proxy \cut{(\eg, 10-tree RF, Tiny Model Adapter in Figure~\ref{fig:framework})}\revb{(\eg, a 10-tree RF)}: $r_{\mathit{eval}} = \Delta\mathit{perf}_{\mathit{tiny}} - \lambda \cdot \mathbf{1}[\text{action}{=}\text{GT-repair}]$, providing ranking signals without overfitting to the downstream model. \emph{(iii) Episode-terminal} $R_{\mathit{final}} = \alpha \cdot \Delta\mathit{score} + \beta \cdot R_{\mathit{keep}} - \gamma \cdot C_{\mathit{repair}}$: $\Delta\mathit{score}$ is the proxy gain over the zero-cost baseline, $R_{\mathit{keep}}{=}n_r/n_{\mathit{orig}}$ the retention rate, $C_{\mathit{repair}}$ normalized GT cost. Adaptive interval $N = \lceil |E|/50 \rceil$ keeps per-episode evaluation cost roughly constant across datasets. \rev{Defaults are $\alpha{=}5.0$, $\lambda{=}0.03$, and $\beta{=}0.2$ for classification/clustering versus $\beta{=}1.0$ for regression, reflecting regression's greater sensitivity to training-set reduction.}
 516
 517  \textbf{Network architecture.}
 518  Both stages use Dueling Double DQN with soft target updates ($\tau{=}0.1$), separating state-value from action-advantage for efficiency on the many low-impact errors typical of cleaning. Stage-1 sees only performance signals (all its actions are cost-free); Stage-2 sees mixed signals with cost penalties.

 558  \begin{definition}[Budget-Constrained Set Function Maximization (BSFM)]
 559  \label{def:bsfm}
 560  Given a finite ground set $U$, a set function $f: 2^U \to \mathbb{R}_{\geq 0}$, element cost function $w: U \to \mathbb{R}_{\geq 0}$, and budget $B \geq 0$, BSFM solves $S^* = \arg\max_{S \subseteq U} f(S)$ subject to $\sum_{u \in S} w(u) \leq B$. \rev{Already for modular $f$ (item values summing independently) and non-uniform $w$, the decision form is NP-complete: it is exactly the 0-1 Knapsack problem~\cite{DBLP:books/fm/GareyJ79}.  563  \begin{theorem}[NP-Completeness of Demand-Driven Cleaning]
 564  \label{thm:npcomplete}
 565  Under the assumption that the downstream model class admits polynomial-time training and evaluation (\eg, decision trees, $k$-nearest neighbors, or fixed-depth ensembles), the decision form of the cost-constrained cleaning policy optimization in Eq.~\eqref{eq:objective} is NP-complete.
 566  \end{theorem}
 567
 568  \begin{proof}
 569  \emph{(1) NP membership.} For a candidate policy \rev{$\pi: E \to O$}, feasibility (cost) is $O(K)$; objective evaluation (apply $\pi$, train $M$, compute $\mathit{Perf}$) is polynomial under the model-class assumption.

 845      n_total = len(X_clean)
 846      if n == 0:
 847          return 0.0, 0.0
 848
 849      # Authenticity: fraction of rows matching clean data exactly

 851      correct = 0
 852      for i in range(compare_len):

 854              correct += 1
