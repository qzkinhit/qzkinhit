一 圆括号还是方括号

判断规则只看括号前面是什么。前面是一个名字时，圆括号表示调用这个函数或方法，方括号表示从这个容器里取值。前面什么都没有时，方括号推导式产出列表，圆括号推导式产出生成器。

括号前面写法含义例子
名字名字()调用函数或方法len(a) print(x) a.append(x)
名字名字[]按下标或键取值a[0] d['key'] s[i] a[1:3]
空[... for ...]列表推导，得到列表[x**2 for x in range(5)]
空(... for ...)生成器，只是一个惰性对象(x**2 for x in range(5))
小测 1 圆括号还是方括号　

二 和其他语言不同的写法

Python 把“问容器一个数量”的操作做成全局函数，把“让容器修改自己”的操作做成方法。长度、最值、求和、排序出新列表都是全局函数，追加、原地排序、原地翻转是方法。

四 list

remove 的参数是值，pop 的参数是下标，这两个最容易写反。二维数组不能写成 [[0] * n] * m，外层乘法复制的是同一个内层列表的引用，改一行会同时改所有行。

五 set

代码里出现 x in 容器，并且这个容器会随循环变大，就应该用 set。用 list 会让每次查找变成 O(n)，整体复杂度多乘一个 n。

六 dict、defaultdict、Counter

滑动窗口题里经常用 len(cnt) 判断窗口内有几种字符。计数减到 0 时不删键，len(cnt) 就会偏大，这是这类题最常见的错误来源。

七 str

字符串不可变，s[0] = 'H' 会报 TypeError。要修改只能构造一个新字符串。

只判断是否包含用 in，需要下标用 find，不用 index，因为 index 在找不到时会抛异常。

八 算法常用容器

BFS 必须用 deque，list.pop(0) 每次要移动后面所有元素，是 O(n)。堆里放元组 (优先级, 值) 时，优先级相同会继续比较第二个元素，第二个元素不可比较（例如链表节点）就会报错，这时插入一个递增序号作为第二项。

九 类型转换

列表不可哈希，不能放进 set，也不能当字典的键。需要用一组值做键时先转成 tuple。

十 数字与初始化
