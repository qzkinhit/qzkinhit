# 独立背景音乐

`quiet-study.m4a` 是专为本项目生成的原创器乐背景音乐。它只包含温和键盘、稀疏旋律、低音和轻柔混响，没有鼓点、人声或第三方录音采样。题目讲解应由另一个独立的音频播放器播放。

音乐长约 106.67 秒，共 32 小节，四四拍，速度约每分钟 72 拍。它以 C 大调和 A 小调的和声为基础。第二遍对部分旋律、时值和力度作轻微变化。

音符尾音和混响通过循环合成接回文件开头。总采样数对齐 AAC 帧，编码采用 AAC-LC、44.1 kHz、双声道和 160 kbps 目标码率。文件已启用快速起播。浏览器的循环调度可能仍有设备相关的微小间隙。

成品目标响度为负 26 LUFS，真峰值上限为负 6 dBTP。音量已低于拟采用的负 18 LUFS 讲解轨，前端还可以将音乐音量默认设为 16%。这样即使部分移动浏览器不支持程序调整媒体音量，音乐文件本身也有较低响度。应通过分别控制两个播放器来替换音乐和调节人声。

## 复现

需要 Python 3.9 或更新版本、NumPy、FFmpeg 和 FFprobe。脚本不联网，也不下载音乐、音色库或模型。在仓库根目录执行：

```sh
python3 scripts/audio/generate_music.py
```

默认输出本目录下的音频和 `quiet-study.metadata.json`。也可用 `--output` 指定另一个 M4A 文件。临时未压缩音频会在完成后自动删除。脚本使用固定随机种子；相同 NumPy 和 FFmpeg 版本下可复现，跨版本的压缩文件字节未必完全相同。

元数据记录代码与音频的 SHA-256、编配、编码参数、解码后的实测响度、峰值、频带能量、直流偏置及循环接缝。生成脚本会检查编码格式、码率、无削波、响度范围及解码样本数。

本执行环境没有可用于模型审听的音频接口，因此已完成的验证属于信号与编码检查，没有声称完成人耳审听。
